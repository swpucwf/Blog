# 长图处理与切块策略

## 1. 长图为什么是典型难点

长截图、长网页、长票据、长合同页面，几乎每个多模态应用迟早都会遇到。它难在几个问题叠加：

- 内容很多；
- 小字很多；
- 结构复杂；
- 缩小后细节损失严重；
- 整图输入成本高。

处理不好，模型的表现会从「偶尔不稳」变成「系统性不准」——因为每一次输入都丢掉了同一类信息。

## 2. 为什么不能直接把长图缩小

这是长图场景最常见也最致命的错误。把超长截图等比例缩小，通常会发生：

- 字体变得不可辨认；
- 表格线与边界消失；
- 小图标与角标丢失；
- 阅读顺序变得模糊。

对长图来说，问题往往不是模型不够强，而是输入前就已经把信息毁掉了。整图缩小等于主动放弃高频细节，后面换多大模型都补不回来。

## 3. 三个基本策略

**整图粗读**：先让模型对整张图做高层次摘要——这是什么页面、大致分成几个区域、页面主要任务是什么。这一层不追求细节，只建立全局认知。

**切块细读**：按区域或固定窗口切成多个小块，逐块分析——每块有什么内容、是否有关键字段、哪块值得继续深挖。

**汇总归纳**：把每块摘要重新汇总成最终答案，必要时加规则校验。

这本质上是一种分层阅读：先建立地图，再看局部，最后合并结论。

## 4. 切块策略怎么选

| 策略 | 做法 | 优点 | 缺点 | 适用 |
|---|---|---|---|---|
| 固定窗口 | 按固定高度等分 | 实现简单、易批处理 | 可能切断关键区域 | 长网页、后台列表 |
| 带重叠窗口 | 相邻窗口保留重叠区 | 减少边界信息丢失 | 请求数变多，需去重 | 表格、长文档、跨块字段 |
| 版面感知 | 按标题区/正文区/表格区/侧栏区切 | 最符合阅读结构 | 依赖版面分析能力 | 结构清晰的票据与合同 |

实践顺序通常是固定窗口起步，遇到边界丢失再加重叠，最后才上版面感知。三种策略可以混用：整图粗读后判断页面类型，再决定切法。

## 5. 案例：长截图报错分析

一张很长的后台报错截图，可能同时包含顶部导航、中间报错提示、底部日志。建议工作流：

1. 整图摘要，判断页面类型与大致结构；
2. 按垂直方向切成 3 到 6 段；
3. 对每段单独问「是否包含错误信息或关键提示」；
4. 收集最相关的块，再汇总生成答案。

这比直接问「整张图报了什么错」稳定得多——后者要求模型在一次前向里同时完成定位、读字与归纳，任一环节出错都会污染最终答案。

## 6. 案例：长文档字段抽取

长文档抽字段要把任务拆成两类：

**定位类问题**：哪一段包含合同金额、哪个区域有日期、是否存在签章区域。这类问题的答案是一个位置，不要求精确取值。

**抽取类问题**：定位到局部区域后，再做字段提取。

「先定位、再抽取」比整图直接抽字段稳，因为每一步的输入都更小、更聚焦，出错时也能明确指出是定位错还是抽取错。

## 7. 三层 prompt 结构

长图处理可以拆成三层提示，逐层收敛：

```text
【层 1 全局摘要】
请概括这张长图的页面类型、主要结构和核心内容，不需要细节。
```

```text
【层 2 局部切块分析】
请分析这一块区域，提取其中的关键文字、字段、报错信息或重要元素。
```

```text
【层 3 最终汇总】
根据整图摘要和各块分析结果，输出最终结论。如果部分信息不确定，请明确说明。
```

分层的好处是每层职责单一：层 1 建立结构，层 2 提取证据，层 3 组织结论。任何一层出错，都可以单独替换模型或调整提示，而不必推翻整条链路。

## 8. 长图为什么特别适合 Agent

长图场景天然适合分步处理：

1. 判断页面类型；
2. 决定切块方式；
3. 筛选重点块；
4. 调用 OCR 或规则工具；
5. 汇总最终结果。

这五步正好对应「感知 → 规划 → 工具 → 汇总」的 Agent 结构。区别在于规划模块需要额外判断一件事：哪些块值得深挖，哪些块可以只留摘要。这个筛选动作做得好，成本能降一个量级。

## 9. 工程上的四个务实建议

**保留原图**。不要只存缩略图，后续排查都需要回到原图。

**记录切块坐标**。否则模型说某块有问题时，无法回溯到页面位置。

**汇总时保留证据来源**。说明结论来自哪个块、哪个字段来自 OCR、哪个判断来自模型推理。

**允许「不确定」**。长图场景比普通图片更容易出错，系统必须能输出未识别、需人工确认、建议重传清晰版这三种状态。

## 写在最后

长图处理的核心不是找一个更强的模型，而是承认「一次看不完」这个事实，用粗读、切块、汇总把一次任务拆成三次可控的调用。至此三篇专题收束：从[OCR 与文档理解](7-OCR与文档理解)、[多图输入与比较](8-多图输入与比较)到这一篇的切块策略，覆盖了多模态落地里信息密度最高的三种输入形态。
