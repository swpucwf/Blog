# 循环神经网络

## 1. 如何从词向量序列提取句义？

词嵌入已把每个词元变成静态稠密向量（文本数值化解决了一半），第二个关键问题是**如何从一个词向量序列中有效提取整个序列的特征**。例如意图识别要把「播放周杰伦的《稻香》」归入「音乐播放」——已有各词元的词向量，但如何融合成一个代表整句含义的「文本向量」再送分类器？

早期思路的局限逐一排除了别的路：

- **求和/平均**（词袋思路）：完全忽略语序，「我爱你」与「你爱我」向量相同；且把所有词视为同等重要——「播放」「《稻香》」显然比「的」包含更多分类信息，简单求和体现不出。
- **全连接网络（FCN）**：无论「先求和后 FCN」还是「先 FCN 后求和」，为处理变长句子各位置必须**共享同一套权重**，算「《稻香》」的输出时只用它自己的词向量，完全看不到前面的「播放」「周杰伦」——每个词元仍被**孤立处理**，没捕获序列特征。
- **一维 CNN**：借鉴图像经验，卷积核滑过词向量序列能捕捉局部依赖（类似 n-gram），但**感受野固定**——窗口 3 只能看附近 3 个词；堆叠多层可扩大感受野，但对句首句尾的长距离依赖仍难捕捉，且无法预设对所有句子「最佳」的窗口大小。

> **时间步**：模型按顺序逐个处理序列元素，每个离散步骤就是一个时间步；文本场景下一个时间步通常对应一个词元。

## 2. RNN：引入「记忆」

需要一种能「记住」之前看过什么信息的结构。**循环神经网络（RNN）** 的做法是：每一步不仅接收当前输入 $x_t$，还接收来自上一步的「记忆」——隐藏状态 $h_{t-1}$，两者融合生成 $h_t$ 再传给下一步：

$$ h_t = \tanh(U x_t + W h_{t-1} + b) $$

对应结构图：$x_t$ 经输入权重 $U$ 进隐藏层（蓝色虚线），$h_{t-1}$ 经循环权重 $W$ 进隐藏层（橙色虚线），相加过 `tanh` 得 $h_t$；$h_t$ 既作为新「记忆」传给下一步，也可经独立输出层得到 $o_t$。本质上是对全连接网络的改进——$h_t$ 同时包含当前输入和之前所有步的信息「摘要」。

所有时间步共享 $U$ 和 $W$——这让 RNN 能处理任意长度序列并大幅减少参数。这种最基础的结构称 **SRN（Simple Recurrent Network）**或 **Elman Network**。

### 2.1 文本分类示例：逐步累积的 h

「播放周杰伦的《稻香》」→ 分词 → ID 序列 → 词嵌入得 4 个 128 维向量（形状 $(T,E)=(4,128)$）。设隐藏维度 $H=64$、$h_0$ 为零向量，RNN 按序逐步更新记忆：

1. $h_1 = \tanh(U x_1 + W h_0 + b)$ —— 含「播放」
2. $h_2 = \tanh(U x_2 + W h_1 + b)$ —— 融合「播放周杰伦」
3. $h_3$ —— 融合「播放周杰伦的」
4. $h_4 = \tanh(U x_4 + W h_3 + b)$ —— 融合整句

最终隐藏状态 $h_4$ 即整个句子的**动态上下文表示**（「文本向量」），送入全连接分类层得到各意图类别置信度。RNN 成功把变长词向量序列编码成蕴含序列信息的定长特征向量。

### 2.2 从静态 Type 到动态 Token

Word2Vec 学到的是词在字典中的静态含义——无论「周杰伦」出现在哪，输入向量 $x_t$ 不变，这是语言学的 **Type**（抽象类型）；RNN 的 $h_t$ 则随语境变化——「**播放**周杰伦」与「**我喜欢**周杰伦」中，模型分别生成带不同上下文信息的「周杰伦」表示，这是 **Token**（具体实例）。

> 这里的 token 不是「词元」：Type 指抽象通用概念，Token 指概念在特定时空的具体表现。「我一边玩黑神话悟空，一边等黑神话钟馗」有 2 个「黑神话」的 Token、1 个 Type。

Elman 1990 年的实验发现很有说服力：不给任何语法规则、只训练 RNN 预测下一个词，隐藏状态空间会**自发组织出层级结构**——动词和名词映射到不同区域，名词内部进一步区分有生命/无生命，甚至 "boy" 在不同句子位置会按句法角色（主语 vs 宾语）聚类。RNN 不只是在「记忆」历史，它通过预测任务**隐式学会了句法和语义结构**。

> **动态表示 vs 动态词向量**（源教程的辨析，值得记录）：实现从静态到动态跨越的到底是 RNN 还是 ELMo？——**原理机制上是 RNN**：$h_t$ 本质就是随上下文变化的动态向量，最早具备按语境改数值的核心能力；**发展范式上是 ELMo**：2018 年之前人们只把 Word2Vec 这种**查表**向量称作「词向量」，RNN 输出被视为特定任务的**中间状态**；ELMo 确立了「动态词向量」概念并把它做成通用可迁移的预训练特征。一句话：**RNN 发明了机制，ELMo 普及了范式**。

## 3. 从零实现：NumPy 手写与 nn.RNN 对齐

不含偏置的简化公式 $h_t = \tanh(U x_t + W h_{t-1})$（数学书写用列向量 $U x_t$；代码为利用内存布局用行向量 $x_t U$，两者转置关系，本质一致）。

```python
def manual_rnn_numpy(x_np, U_np, W_np):
    B_local, T_local, _ = x_np.shape
    h_prev = np.zeros((B_local, H), dtype=np.float32)  # 每个序列开始前的“空白记忆”
    steps = []
    for t in range(T_local):                # 逐帧处理
        x_t = x_np[:, t, :]
        h_t = np.tanh(x_t @ U_np + h_prev @ W_np)   # 核心公式
        steps.append(h_t)
        h_prev = h_t                        # 状态更新，实现“循环”
    return np.stack(steps, axis=1), h_prev
```

PyTorch 的 `nn.RNN` 做了同样的循环计算但经过优化，关键参数：

| 参数 | 含义 |
|---|---|
| `input_size` (E) | 输入特征维度，NLP 中通常即 `embedding_dim` |
| `hidden_size` (H) | 隐藏状态维度，即「记忆」容量 |
| `num_layers` | >1 构成堆叠 RNN：前一层所有时间步输出作后一层输入 |
| `bias` | 默认 True；示例设 False 与手写版对齐 |
| `batch_first` | 默认 False 输入为 `(T,B,E)`；设 True 更符合直觉的 `(B,T,E)` |
| `bidirectional` | 是否双向 |

注意 `nn.RNN` 内部存放的是**转置后的权重**（`weight_ih_l0.copy_(U.T)`）。把相同输入相同权重喂给两个实现，`torch.allclose(out_manual, out_torch, atol=1e-6)` 返回 `True`——手写实现与框架行为完全对齐。

## 4. 双向循环神经网络（BiRNN）

单向 RNN 计算时刻 $t$ 只用到 $t$ 及之前的信息，但很多任务中词义同时依赖后文：「**苹果**味道不错」vs「**苹果**股票大涨」，看到后文才能确定「苹果」是水果还是公司。早期尝试是**时间延迟**（预测 $t$ 时允许看 $t+M$），但延迟窗口 $M$ 要人工调——太小未来信息不足，太大难以聚焦局部。

**BiRNN** 用两个完全独立的 RNN 叠加：正向从左到右算 $(\overrightarrow{h_1},...,\overrightarrow{h_T})$，反向从右到左算 $(\overleftarrow{h_1},...,\overleftarrow{h_T})$，每个时间步输出拼接：

$$ h_t = [\overrightarrow{h_t} ; \overleftarrow{h_t}] $$

两个方向各有独立权重、在同一损失下**同时训练**——这是它优于「分别训练正反向再合并（线性/对数意见池）」的原因：特征提取协同进行、更好适应目标任务，且彻底消除对延迟参数 $M$ 的依赖。输出维度变 $2H$；PyTorch 中 `bidirectional=True` 即可，`h_n` 第一维为 `num_layers * 2`。

BiRNN 让每个元素都获得完整上下文特征，在 NER、情感分析等任务上优于单向；但两个局限：并未解决**长距离依赖**（两个方向各自仍面临梯度消失/爆炸）；必须处理完整序列才能算反向信息，**无法用于实时预测**（如按用户已输入内容实时推荐下一个词）。

## 5. BPTT：随时间反向传播

RNN 训练是标准反向传播在时间展开图上的直接应用，称 **BPTT（Backpropagation Through Time）**：把 RNN 沿时间展开视作**各层参数共享的深层前馈网络**再执行通用反向传播。总损失 $L = \sum_t L_t$，按加法求导：

$$ \frac{\partial L}{\partial W} = \sum_{t=1}^{T} \frac{\partial L_t}{\partial W}, \qquad \frac{\partial L_t}{\partial W} = \sum_{k=1}^{t} \frac{\partial L_t}{\partial h_t} \cdot \frac{\partial h_t}{\partial h_k} \cdot \frac{\partial h_k}{\partial W} $$

麻烦在中间项——$h_t$ 通过 $h_{t-1}$ 间接依赖之前**所有**时间步，梯度要沿时间一路追溯到序列开端：

$$ \frac{\partial h_t}{\partial h_k} = \prod_{i=k+1}^{t} \frac{\partial h_i}{\partial h_{i-1}} $$

**这个连乘形式正是 RNN 一切问题的根源。**

## 6. RNN 的局限性

### 6.1 梯度消失与梯度爆炸

传播的导数矩阵 $\frac{\partial h_i}{\partial h_{i-1}} \approx J_{\tanh}(U x_i + W h_{i-1}) \cdot W$，从 $k$ 步到 $t$ 步要经历 $t-k$ 次与 $W$ 及激活导数矩阵相乘：

- **梯度消失**：$W$ 范数 <1 或 $\tanh'$（最大 1、通常小于 1）使连乘项衰减，长序列下遥远过去的梯度信号趋近 0；
- **梯度爆炸**：$W$ 范数 >1 时梯度指数增长至 Inf/NaN，训练崩溃。爆炸相对容易发现和处理，常用**梯度裁剪**——梯度范数超阈值就整体缩放到阈值。

### 6.2 长距离依赖

梯度消失比爆炸更棘手，直接导致**长距离依赖问题**，两个视角都值得一记：

- **反向传播视角**：模型学不到相距遥远的词之间的依赖。如《西游记》长句——要理解结尾神仙提「弼马温」是在**嘲讽**，模型必须关联到开头「弼马温」是低微官职这一事实，但误差梯度从「嘲讽」传回「弼马温」可能已衰减为零。Werbos 指出 BPTT 计算梯度本身是精确的，但长序列中的连乘效应是**数学上的必然**。
- **正向传播视角**（信息遗忘/近期偏置）：每一步信息都被新输入和 $W$「稀释」「覆盖」，足够多时间步后序列最初的信息在 $h$ 中所剩无几——两个句子即使开头不同，经过很长的相同后续后最终隐藏状态可能几乎没有差别。

### 6.3 单向性与出路

常规 RNN 信息流单向，$t$ 时刻用不到未来上下文；双向 RNN 与堆叠深度 RNN 都是变体，但**都没从根本上解决梯度传播带来的长距离依赖**。攻克这一难题的是两种门控 RNN：LSTM 与 GRU。

## 7. LSTM：门控机制

常规 RNN 的状态更新太「粗暴」：新信息与旧信息无差别混合后强制过权重矩阵 $W$，无论重要与否都在反向传播中形成梯度累乘。LSTM（Hochreiter & Schmidhuber, 1997）的设计哲学是**赋予网络自行决定信息取舍的能力**——引入**门控机制（Gating Mechanism）**，让模型在训练中学会有选择地让信息通过、遗忘或输出。

### 7.1 双轨并行与「门」

与 RNN 单一 $h_t$ 不同，LSTM 有两个状态并行传递：

- **细胞状态 $c_t$（Cell State）**：核心，原始论文称**「恒定误差旋转木马」（CEC）**——一条「信息高速公路/传送带」负责传递**长期记忆**，信息在其上流动只经过按元素的加权与相加、**没有额外的矩阵连乘**，极大缓解梯度消失；
- **隐藏状态 $h_t$**：与 RNN 类似，代表**短期记忆**和最终输出，计算依赖当前 $c_t$。

「门」的灵感来自数字电路的逻辑门，实现极简：一个 **Sigmoid 激活的全连接层**，输入通常是 $[h_{t-1}, x_t]$ 拼接向量，输出 (0,1) 区间向量，再与另一向量**按元素乘法**——某维接近 1 即「允许完全通过」，接近 0 即「阻止/遗忘」。门控同时也是为解决**权重冲突**：输入门保护细胞状态不受无关**输入**干扰，输出门保护其他单元不受细胞状态中无关**记忆**干扰。

### 7.2 单元结构与四步计算

$t$ 时刻接收 $x_t$、$h_{t-1}$、$c_{t-1}$，经三门一 `tanh` 输出 $c_t$、$h_t$（图中 `σ`=门、`⊙`=按元素乘、`+`=按元素加；拼接 $[h_{t-1},x_t]$ 后一次矩阵乘法等价于分开乘再加，是框架常用优化）：

1. **遗忘门**——决定从 $c_{t-1}$ 丢弃什么：$f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)$，逐维「遗忘系数」1≈完全保留、0≈完全丢弃（原始 1997 版 LSTM 没有遗忘门，Gers 2000 年引入）；
2. **输入门与候选记忆**——决定存什么：$i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i)$ 决定更新哪些值；$\tilde{c}_t = \tanh(W_c \cdot [h_{t-1}, x_t] + b_c)$ 生成准备写入的新内容（这步与常规 RNN 计算几乎相同）；
3. **更新细胞状态**：$c_t = (f_t \odot c_{t-1}) + (i_t \odot \tilde{c}_t)$——先忘掉该忘的，再写入筛选过的新的；
4. **输出门**——$o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o)$ 决定输出的部分，$h_t = o_t \odot \tanh(c_t)$ 只吐出过滤后的版本，传给下一步。

### 7.3 梯度高速公路：LSTM 为何能缓解长距离依赖

关键在于 $c_t$ 的更新法则。考察梯度沿细胞状态的反向传播：

$$ \frac{\partial L}{\partial c_{t-1}} = \frac{\partial L}{\partial c_t} \odot \frac{\partial c_t}{\partial c_{t-1}} = \frac{\partial L}{\partial c_t} \odot f_t $$

因为 $c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t$ 中只有第一项含 $c_{t-1}$，偏导直接就是遗忘门 $f_t$——**梯度只按元素乘了 $f_t$，没有经过权重矩阵乘法**！追溯到更早的 $k$ 时刻：

$$ \frac{\partial L}{\partial c_k} = \frac{\partial L}{\partial c_t} \odot (f_t \odot f_{t-1} \odot \dots \odot f_{k+1}) $$

如果模型在训练中发现某个早期信息很重要，它可以把中间所有时间步的 $f_t$ 学到接近 1，梯度就几乎无衰减地从序列末端传到开端。本质区别：RNN 的长距离依赖是**结构性缺陷**，LSTM 把它转化成了**可学习的问题**——通过优化损失自行调整门控，决定哪些信息长期记忆（$f_t \approx 1$）、哪些舍弃（$f_t \approx 0$）。

> 所以措辞要准确：不说 LSTM **解决**了梯度消失，而是**缓解**——$f_t$ 哪怕 0.99，足够长的序列连乘后梯度依然衰减，只是相比 RNN 几十步就出问题已属巨大飞跃。梯度传播路径仍是两条：走 $h_t$ 的那条和 RNN 一样有衰减风险，走 $c_t$ 的那条才是主干道。

### 7.4 手写 LSTM 与实现层优化

不含偏置的简化版 LSTM 前向传播公式与代码骨架：

```python
for t in range(T_local):
    x_t = x_np[:, t, :]
    f_t = sigmoid(x_t @ U_f + h_prev @ W_f)            # 1. 遗忘门
    i_t = sigmoid(x_t @ U_i + h_prev @ W_i)            # 2. 输入门
    c_tilde_t = np.tanh(x_t @ U_c + h_prev @ W_c)      #    候选记忆
    c_t = f_t * c_prev + i_t * c_tilde_t               # 3. 更新细胞状态
    o_t = sigmoid(x_t @ U_o + h_prev @ W_o)            # 4. 输出门
    h_t = o_t * np.tanh(c_t)
    h_prev, c_prev = h_t, c_t                          # 状态传递
```

框架实现的实际优化：三个门加候选记忆共**四次对同一拼接向量的独立线性变换**，PyTorch/TensorFlow 把四个权重按「与 $x_t$ 相关」「与 $h_{t-1}$ 相关」分别拼成两个大矩阵 $W_x$、$W_h$——四次小矩阵乘合并成两次大矩阵乘再切分，更好利用 GPU 并行。

## 8. GRU：更轻的门控

GRU（Cho 等，2014）最初在 **RNN Encoder-Decoder** 框架下为解决统计机器翻译的短语表示而提出，比 LSTM 更易训练。两大核心改动：

- **合并细胞状态与隐藏状态**：不再区分 $c_t$ 与 $h_t$，只有一个兼具长期记忆与输出功能的状态在时间步间传递（结构回到 RNN 式单轨道）；
- **三门简化为两门**：**更新门 $z_t$** 类似 LSTM 中耦合起来的遗忘门+输入门，同时决定保留多少旧信息、接收多少新信息；**重置门 $r_t$** 决定计算候选状态时忽略多少旧信息。这让每个隐藏单元能自适应捕捉**不同时间尺度**的依赖，更灵活处理长短句法结构。

四步计算：

1. 重置门：$r_t = \sigma(W_r \cdot [h_{t-1}, x_t] + b_r)$
2. 更新门：$z_t = \sigma(W_z \cdot [h_{t-1}, x_t] + b_z)$
3. 候选记忆：$\tilde{h}_t = \tanh(W_h \cdot [r_t \odot h_{t-1}, x_t] + b_h)$ —— $r_t$ 某维接近 0 则算候选时完全忽略 $h_{t-1}$ 对应维
4. 最终状态：$h_t = z_t \odot h_{t-1} + (1 - z_t) \odot \tilde{h}_t$ —— $z_t$ 是 0~1 的「开关」：接近 1 倾向保留旧信息，接近 0 倾向采用新信息

## 9. LSTM 的两个经典变体

- **窥孔连接（Peephole Connections）**：标准 LSTM 的门只看得见 $x_t$ 和 $h_{t-1}$，无法直接「看到」它们控制的细胞状态——尤其输出门关闭时 $h_{t-1} \approx 0$，门控单元失去细胞内部状态的重要信息。窥孔连接允许遗忘门/输入门决策时「窥视」$c_{t-1}$、输出门「窥视」刚更新的 $c_t$：各门公式加一项 $V \odot c$（$V$ 为对角权重矩阵，按元素乘保持计算局部性）。Gers & Schmidhuber 的实验表明它在**精确计时与计数**任务（如生成特定时间间隔的脉冲序列）上显著优于标准 LSTM。
- **耦合输入/遗忘门（CIFG）**：「遗忘旧信息」与「写入新信息」本是同一决策的两面——要写入多少新内容，就得先腾出多少空间。直接令 $i_t = 1 - f_t$，细胞状态更新简化为 $c_t = f_t \odot c_{t-1} + (1-f_t) \odot \tilde{c}_t$，逻辑更直观且减少参数。Greff 等人的大规模消融（*LSTM: A Search Space Odyssey*）验证 CIFG 不降性能地省开销，并给出三条对工程实践极具价值的结论：**遗忘门和输出激活函数是 LSTM 最关键的组件**（移除显著降性能）；各**超参数独立性高**（可单独调学习率，无需复杂组合搜索）；在线 SGD 训练中**动量作用有限**。

> **补记**：ch3 一整章的叙事线其实是一组「问题→结构」的对偶——序列特征提取难 → 记忆循环 $h_t$；单向信息不够 → BiRNN 拼接；连乘梯度消失 → 细胞状态走「按元素乘门」而非「矩阵乘」；三门太贵 → GRU 两门合并。抓住「矩阵连乘 vs 逐元素门控」这一条数学主线，RNN 家族的所有结构变体都能自己推出来。
