# 多模态全景与图文模型

## 1. 多模态的定义与内涵

真实世界的信息不只以文字存在——图片、视频、语音、音乐、传感器、布局与结构化信号共同构成认知的「输入流」。**多模态学习**关注的是如何在这些异构信息之间建立联系，完成理解、生成与决策。

**模态（Modality）** 在工程语境里指信息的**感知/表达通道**，即同一语义在不同载体上的呈现形式。载体不同，数据层面天然有差异：文本是离散 token 序列；图像是 $H \times W \times C$ 的像素网格；语音是连续波形或谱图；传感器是多路同步时间序列（还带漂移、缺失、噪声）。统计特性（局部性/全局性、时序依赖、尺度变化、噪声分布）不同，预处理、采样与建模方式也不应「一把梭」。因此多模态系统通常为每种模态配各自的编码器，先把异构信号映射为可计算表征，再进入对齐、融合与推理。

> **微观多模态**：除了跨物理媒介的模态，文本内部也有「结构形态」的质变——**Text-to-Code**（代码有更严密的语法约束）、**Text-to-Table**（表格是结构化二维信息）虽输入输出都是字符流，但信息组织形式变了，可视为广义的多模态转换。

一个可操作的定义：**当系统需要同时处理两种及以上「本质异构」的模态，并显式建模它们之间的语义关系（对应、互补、约束）时，就叫多模态**。它不等于把多路数据简单拼在一起，也不应只看输入输出个数——关键是模型是否真的利用了模态间的互补信息。工程上最常见的形态：图文问答（VQA）、以文本为条件生成图像/音频/视频、以及同时接收并输出多模态内容（看图对话并用语音回答）。

### 1.1 两条历史路线

多模态研究并非近年才出现，其脉络可概括为两条相互关联的路线：

**（1）多模态交互**：源于人机交互（HCI）与多通道界面研究，强调不同输入通道的语义互补与消歧。Richard Bolt 1980 年在 SIGGRAPH 演示的 **「Put-That-There」** 系统是经典案例——把语音命令与同步指向结合，让「that/there」这类指示词借助空间指点获得明确指代，完成图形对象定位与操作。此类工作以规则、语法或时序约束实现跨通道整合，重点在交互机制而非大规模学习统一表示。

**（2）多模态表征对齐**：学习一个（或一组）潜在空间，使不同模态的表示在其中可比、对语义对应保持一致。数学基础更早——Hotelling 的**典型相关分析（CCA）** 通过线性投影最大化两组变量的相关性，为「共享子空间」提供工具；检索领域的 **LSA/LSI** 虽只处理文本，但以低维语义空间 + 空间邻近刻画相似性的范式，为「用向量空间承载语义」奠定方法论。随图文检索等跨模态任务发展，研究重心转向「可迁移的联合嵌入空间」：CCA 及其核化形式被系统总结为学习共同表征的工具；深度学习中 Hadsell 等的**对比损失**给出「拉近正样本、推远负样本」的早期形式化；**ConVIRT** 在配对图文上做双向对比预训练；**CLIP** 把该范式扩展到更大规模图文对，并在零样本迁移上展示共享嵌入空间对齐的泛化价值，推动这条路线进入快车道。

> **误区辨析**：① 把「多源/多路数据」当多模态——关键不在数据路数多，而在**模态是否异构、信息是否互补、系统是否真的做了对齐/融合/协同推理**。多篇文本、多视角图像、多图拼接往往仍是同模态扩展；而「一张图 + 一句描述」这种最简单的图文对，只要目标是学习跨模态语义关系，就已经是多模态。② **多模态 ≠ 多任务学习**——前者讨论信息来源的异构与融合，后者讨论目标函数的并行优化，可以组合但不能互相替代。

## 2. 多模态认知图谱

### 2.1 任务四级递进

按输入输出依赖与任务复杂度，多模态任务可归为四个递进层级（以图文为例，逻辑同样适用于视频、音频、传感器）：

1. **基础理解与检索**：判断跨模态匹配度或从库中找对应项。典型是**图文检索**（以文搜图/以图搜文），正是 CLIP 这类双塔结构擅长的领域；同样逻辑可延伸到音频-文本检索、多传感器片段检索。ImageBind 等前沿工作甚至把图像、文本、音频、深度、热成像、IMU 绑到同一嵌入空间，让「检索/匹配」天然跨多种模态组合。这一层主要完成「特征对齐」与跨模态一致性判断。
2. **定位与结构化理解**：把语言或符号「落到可定位的证据」——**视觉指代/定位（Visual Grounding）** 解决「指到哪/是哪一个」，是细粒度 VQA 与具身智能的前置能力；可扩展为音频/视频 Grounding（定位时间片段或音频事件区间）、传感器时序对齐；**文档与图表理解**（OCR、表格布局、坐标轴）也是高频结构化输入。这一层决定后续推理是否建立在准确证据上。
3. **生成与转换**：跨模态创造新信息——**图生文**（Image Captioning「看图说话」）、**文生图**（Stable Diffusion 以提示控制像素）；LLaVA 等视觉语言模型则通过视觉-语言对齐 + 指令数据增强「可对话、可解释、可执行指令」的生成；再推广到文生音频/音频生文、视频→文本总结、传感器→告警报告。这一层解决跨模态 Mapping 与条件生成。
4. **复杂推理与控制**：结合外部知识与上下文多步思考或行动——视觉问答/对话/多模态推理要围绕问题组织证据、多步推理并给出可追溯结论；更进一步是**具身智能**（「去厨房拿那个红色的苹果」要理解场景、规划动作并执行）。这一层受限于对齐精度、证据可追溯性与长序列建模成本。

### 2.2 五大挑战

Baltrušaitis 等的多模态机器学习综述提出「五大挑战」，在 LLM 时代仍是审视多模态架构的高频框架：

| 挑战 | 核心关注 | 主要难点 | 演进与策略 |
|---|---|---|---|
| **表征** | 异构数据映射到统一空间 | 离散符号 vs 连续像素，噪声与冗余各异 | 各模态专用编码器 + 共享 token 空间/Transformer 交互；或先统一 token 化再建模 |
| **转换** | 模态间映射与生成 | 一对多映射歧义，语义一致性与真实性 | 从 Captioning 到 Diffusion 的多向生成 |
| **对齐** | 跨模态元素对应关系 | 识别不同模态中同一实体/事件的子结构 | CLIP 对比学习在大规模数据上拉近配对距离 |
| **融合** | 信息整合与推理 | 消除歧义、抑制冲突带来的幻觉 | Cross-Attention 等深度交互（如 LLaVA）替代简单拼接 |
| **协同学习** | 知识跨模态迁移 | 用高资源模态（文本）辅助低资源模态 | 跨模态蒸馏、伪标注、联合预训练、缺失模态鲁棒训练 |

## 3. ViT：把图像变成 Token 序列

过去十年 CV 由 CNN（ResNet 等）主导，NLP 则由 Transformer 主导。2020 年 Google 的 **ViT（Vision Transformer）** 提出一个追问：**既然 Transformer 擅长处理 token 序列，能不能把图像切成 Patch、每个 Patch 当一个 Token，直接用 Transformer 做图像识别？**

### 3.1 序列化图像

Transformer 输入是 1D 向量序列，图像是 2D 网格。ViT 的处理直接而「暴力」：

**（1）Patch Embedding**：把图像 $\mathbf{x}\in\mathbb{R}^{H\times W\times C}$ 切成 $N$ 个 $P\times P\times C$ 的 Patch，展平得 $\mathbf{x}_p\in\mathbb{R}^{N\times(P^2 C)}$，其中

$$ N = \frac{H\cdot W}{P^2} $$

再用可学习线性投影 $\mathbf{E}\in\mathbb{R}^{(P^2 C)\times D}$ 把每个 Patch 映射为 $D$ 维向量——实现上等价于一个 **kernel=$P$、stride=$P$** 的卷积。

**（2）`[CLS]` Token**：借鉴 BERT，在序列开头拼一个可学习分类令牌，它像「读写全局信息的槽位」，通过自注意力在层间从各 Patch 聚合信息；最终只用该位置输出代表整张图像分类。

> 例：$224\times224$ 图像、$P=16$ 会切出 $14\times14=196$ 个 Patch，加上 `[CLS]` 后序列长度为 **197**。

**（3）位置编码**：加可学习 1D 位置编码 $\mathbf{E}_{pos}\in\mathbb{R}^{(N+1)\times D}$ 保留空间信息。最终输入序列：

$$ \mathbf{z}_0=[\mathbf{x}_{class};\mathbf{x}_p^1\mathbf{E};\dots;\mathbf{x}_p^N\mathbf{E}] + \mathbf{E}_{pos} $$

### 3.2 架构细节

ViT 尽可能保持 Transformer 原貌——这种「无修饰」设计反而带来极强扩展性：

- **Encoder-only + Pre-Norm**：标准 Transformer Encoder 堆叠（MSA + MLP），LayerNorm 移到每个子层输入位置（与 GPT-2/3 一致）；
- **分类读出**：$\mathbf{y}=\mathrm{LN}(\mathbf{z}_L^{0})$，取最后一层第 0 个 token（`[CLS]`）接 MLP 分类头；预训练时 Head 含一个隐藏层，微调常简化为单层线性；
- **高分辨率微调的 2D 插值**：位置编码是 1D 可学习向量，当微调分辨率变化导致 $N$ 变化时，把预训练的 $\mathbf{E}_{pos}$ 视作 $h\times w$ 网格做 **2D 插值**适配——这是 ViT 少数显式注入「2D 结构」的地方。$14\times14$ 的位置编码可双线性插值到 $24\times24$（$384/16=24$）；
- **全局交互**：每个 Patch 就是 Token，自注意力在**第一层**就能让任意两个 Patch 交互（CNN 需堆叠多层卷积才能扩大感受野）。代价是 $O(N^2)$ 复杂度：Patch 越小 $N\propto 1/P^2$ 越大，计算量按 $1/P^4$ 爆炸——这就是 ViT 不把 Patch 设太小的原因。

> **为什么微调时放大图像**：预训练数据量大、为省算力用标准分辨率；微调面向特定任务、数据量小，用更高分辨率（如 $384\times384$）让模型「看清」更多细节，追求更高精度。

### 3.3 关键特性：弱归纳偏置与统一架构

**归纳偏置（Inductive Bias）** 是模型处理数据时预设的「偏见/假设」。CNN 天然假设图像**局部性**（相邻像素相关）与**平移等变性**（猫在哪个位置都是猫），带着「有色眼镜」看图，小数据上也能快速泛化；而 ViT 的自注意力是全局的，把图像看作长序列，显式 2D 结构只出现在切 Patch 与位置插值两处——像一张白纸，必须靠大量数据自己发现「相邻 Patch 往往属于同一物体」（空间模式）与高层语义组合规则（语义模式）。

弱归纳偏置带来两个结果：**架构统一性**——ViT 证明 Transformer 是通用计算原语，CV 与 NLP 终于在底层架构上统一（都用 Transformer 处理 Token 序列），为多模态大模型铺路（图像和文本都变成 Token，就能在一个模型里同时处理）；**数据饥渴**——中小数据集（ImageNet-1k）从头训练时 ViT 往往不如同规模 CNN，但在超大规模（ImageNet-21k、JFT-300M）预训练后迁移下游，扩展性更强（scale 越大越吃香）。

## 4. CLIP：连接图文的语义空间

ViT 统一了视觉的**底层架构**，但模型仍不理解「一张猫图」与单词「Cat」的联系。2021 年 OpenAI 的 **CLIP（Contrastive Language-Image Pre-training）** 统一了图文的**语义空间**：借 Embedding 把高维非结构化数据映射到低维稠密空间，并让图像向量与文本向量在**同一空间**具有几何关联——「猫图」的 $V_{img}$ 应与「Cat」的 $V_{text}$ 距离近、夹角小，这就是**语义对齐（Alignment）**。

### 4.1 双塔结构

CLIP 采用经典**双塔**：

- **图像编码器**：探索改进的 ResNet（ResNet-D 改进 + 抗混叠下采样减少信息折叠，末端全局平均池化换**注意力池化**）与 ViT（仅在两嵌入相加后加一个 LayerNorm + 不同初始化）。同计算预算下 **ViT 表现更优，效率约高 3 倍**；
- **文本编码器**：选类似 GPT-2 的 **Decoder-only** 而非 BERT，用自注意力掩码确保只看前文；序列以 `[SOS]` 开始、`[EOS]` 结束，只取最后一层 `[EOS]` 位置的特征作整句语义——该位置已通过自注意力聚合全句信息。

一个 Batch 含 $N$ 个图文对：图像与文本分别过编码器，投影到联合空间形成 $I_1..I_N$ 与 $T_1..T_N$；计算两两点积得 $N\times N$ **相似度矩阵**——**对角线（蓝色块）** 是真实图文对（正样本），**非对角线（白色块）** 是错误组合（负样本）。训练目标：**最大化对角线、最小化非对角线**。当模型让 $I_{dog}\cdot T_{dog}$ 变大，就是在高维空间推着「狗的图片向量」与「Dog 单词向量」靠近；让 $I_{cat}\cdot T_{dog}$ 变小，就是让它们远离。在 **4 亿对** 数据上重复这个过程，CLIP 学会了把视觉概念与语言概念紧密绑定——Embedding 成为连接视觉与语言的「通用货币」。

### 4.3 零样本推理与提示工程

CLIP 最具革命性的特性是**零样本推理**：传统 CV 模型只能识别训练时定义的类别，CLIP 把「分类任务」重构为「**图文匹配任务**」，打破固定类别限制。

推理时不再让模型输出类别 ID，而是判断图像与候选句子（如「A photo of a {label}.」）的相似度，取最高者。**提示工程**在这里是必需的：训练数据多为句子而非单词，直接输入单词会造成歧义（论文提到的 "boxer" 既可能是拳师犬也可能是拳击手），且与预训练分布有差异；把类别标签填入模板句子、生成一组文本向量再比对，使 CLIP 无需微调即可迁移到任意分类任务，成为真正的「开放词汇」分类器。

### 4.4 局限

CLIP 打通了视觉与语言的壁垒：其 Embedding 语义线性强、鲁棒性好，**Stable Diffusion** 等扩散模型常用 CLIP/OpenCLIP 文本编码器把提示词变成条件向量；对风格、光照、草图、卡通的鲁棒性也强于仅 ImageNet 训练的模型。但它并非完美：

- **细粒度分类弱**（区分波音 747 与 777、特定花卉品种），细微差别在海量图文对中被淹没；
- **逻辑计数与空间关系弱**（「几个红色气球」「车在房子左边还是右边」）——对比损失难捕捉组合性语义；
- **专业领域（医学影像、遥感）零样本性能显著下降**，通常需针对性微调。

## 5. 小结：两点统一

回到五大挑战：**ViT 解决了「表征」的统一性**——打破 CNN 对视觉的统治，证明 Transformer 是通用计算原语，Patch Embedding 把图像「序列化」为 Token，与语言在底层架构一致；**CLIP 解决了「对齐」的普适性**——对比学习把异构图文映射到同一联合嵌入空间，Embedding 成为跨模态桥梁，无需微调即可零样本迁移。尽管 CLIP 在细粒度与复杂逻辑上仍有短板，它已为后续的**多模态生成**与**复杂推理**提供了关键的语义地基。

> **补记**：这一篇可压缩成一句「两次统一」——ViT 统一**架构**（图像 → Token 序列），CLIP 统一**语义空间**（图文 → 同一嵌入空间 + 对比对齐）。后续所有视觉语言模型（BLIP-2、LLaVA、Chameleon）都建立在这两块地基上：要么用 ViT/CLIP 当视觉端，要么直接复用 CLIP 的文本编码器做生成条件。
