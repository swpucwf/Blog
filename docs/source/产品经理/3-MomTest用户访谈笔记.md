# Mom Test 用户访谈笔记

> 笔记缘起：The Mom Test 来自 Rob Fitzpatrick 的同名访谈方法书，easy-vibe 把它作为附录完整讲了一遍。这篇笔记只记一件事：**怎么让访谈产出证据，而不是礼貌。** 它和 JTBD 是一对——JTBD 写下假设，Mom Test 检验假设。

## 内容概览

- 为什么访谈总会得到「好听但没用」的假阳性
- 三个提问原则
- 容易问废 vs 更有价值 对照表
- 一次访谈的基本顺序
- 和 JTBD 的配合用法

---

## 1. 假阳性从哪来

直接询问对方是否喜欢某个想法，往往只会得到「挺好的啊」「听起来很有用」「你可以试试」。这些回答没有错，只是很难支持产品决策。**就算是你妈妈，也很难直接告诉你「这是个烂想法」。** 原因不是不诚实，而是对方不想伤害提问者、会下意识鼓励、容易顺着问题的措辞回答。

三个心理机制值得记住：

- 人会下意识地保持礼貌，尤其当对话对象和自己有关系时
- 人会高估未来的自己——「如果有的话我应该会用」常常不等于真的会用
- 提问方式本身就在引导答案——「这个功能对你是不是很有帮助」已经偷偷把正确答案塞进了问题里

所以 The Mom Test 的重点不是访谈谁，而是**问题怎么组织**：不要把访谈做成寻找认可。

---

## 2. 三个提问原则

1. **少谈自己的点子，多谈用户过去的真实经历。** 访谈者一开场大谈方案，对方就很容易切换到「配合」模式。改成问：最近一次遇到这个问题是什么时候？当时你在做什么？你最后是怎么处理的？哪一步最麻烦？
2. **少问抽象意见，多问具体事实。** 「听起来不错」无法指导决策；「上周为这事折腾了 2 小时」「我现在用 Excel 加微信硬撑」「上个月已经为类似工具花过钱」才是能判断问题强度、频率和付费可能的信息。
3. **少问用户想要什么方案，多看他现在怎么解决问题。** 用户擅长描述困扰，不擅长设计方案。问「你想不想要 AI 自动做这个」只能得到一个模糊态度；问「你现在用什么方法处理、为什么选这种方式、它哪里不够好」才能看清真实需求。

一句话总结：和「你会不会用」相比，「你上次怎么处理这件事的」往往更接近真相。

---

## 3. 对照表：什么问题容易问废

每个访谈前都值得过一遍的表：

| 容易问废的问题 | 更有价值的问题 |
| --- | --- |
| 你觉得我这个想法怎么样？ | 你最近一次遇到这个问题是什么时候？ |
| 如果有这个产品你会用吗？ | 你现在是怎么处理这件事的？ |
| 你愿意为这个功能付费吗？ | 你上次为了这个问题花过钱吗？花在什么上？ |
| 你觉得这个功能重要吗？ | 这个流程里最烦、最慢、最不放心的是哪一步？ |
| 你想不想要一个 AI 帮你自动做？ | 你现在为什么还没有找到更顺手的解决办法？ |

改写的共同点：从意见走向事实、从未来走向过去、从自己的方案走向用户的问题。

---

## 4. 一次访谈的基本顺序

1. **开场**说明来意：「我最近在研究大家怎么处理这类问题，想先了解真实情况，不是来卖东西的」——降低对方给正面反馈的心理负担
2. **从最近一次真实经历问起**：最近一次遇到这个问题是什么时候？当时发生了什么？第一反应怎么处理的？对话一旦进入具体事件，信息质量会明显上升
3. **往下追问行为、成本和替代方案**：现在用什么办法解决、最不舒服的地方是什么、为此花了多少时间金钱精力、试过别的方法吗为什么没继续
4. **最后判断痛感和优先级**——不直接问「痛不痛」，从细节判断：是否经常遇到、是否已在主动补救、是否已愿意付出成本、讲述时是否带着明显情绪

访谈的主体是对方，不是提纲。听到「上周」「我后来只好」「我已经花了」这类具体线索，应顺着经历继续追问，而不是急着逐题打勾。

## 5. 和 JTBD 的配合

如果说 [JTBD](/source/产品经理/2-JTBD需求理论笔记) 帮看清「用户想完成什么进展」，Mom Test 就是在确认**这个 job 是不是真的存在**。接起来用：

1. 先用 JTBD 假设一个 job
2. 再用 Mom Test 的方式，问用户最近一次真实经历
3. 检验这个 job 是否高频、真实、值得优先做

比如假设是「当我准备投递实习时，我想快速把旧简历改成贴合岗位的版本」，就用「最近一次改简历是什么时候、怎么改的、哪一步最卡、有没有为这事花过钱」去核对。

---

## 写在最后

Mom Test 读完后最大的改变是：访谈前先把所有「你觉得……怎么样」句式删掉，只留下能被具体经历回答的问题。付钱意愿同理——最好的验证不是问出来的，是让用户预付定金试出来的（参见 [1-如何判断一个好点子](/source/产品经理/1-如何判断一个好点子) 的五步判断法）。
