# 经典 RL 与 LLM 策略

## 1. 强化学习的最小框架

强化学习（RL）的核心是学习如何根据当前情境选择动作，以获得最大**累积奖励**。

Agent 与环境持续交互：每一步观察状态、选择动作，环境产生新状态并给出奖励；交互产生**轨迹**（状态→动作→奖励→新状态……），策略优劣最终体现在轨迹质量上。

![配图](https://raw.githubusercontent.com/swpucwf/MyBolgImage/main/img/aiagent_fig8-1.svg)

<p>图 1：强化学习 Agent—环境交互循环</p>

两个特征区别于监督学习与无监督学习：

- **试错搜索**：没有老师直接告诉正确答案，Agent 必须自己摸索；
- **延迟奖励**：动作影响可能多步之后才显现，像一步好棋的价值要到终局才看出。

由此带来**探索与利用权衡**：一直走熟悉的路学不到新东西；一直乱试永远到不了终点。

五个核心要素：

- **动作空间**：离散（棋类）或连续（机器人关节）；
- **策略**：给定状态下怎么做；
- **奖励信号**：即时反馈，但目标是最大化长期而非即时奖励；
- **价值函数**：估计从某状态出发未来总共能获得多少累积奖励；
- **环境模型**（可选）：预测环境对动作的响应。

| Agent 类型 | 环境 | 动作空间 | 奖励 |
|---|---|---|---|
| 新生小羚羊 | 地形、重力、身体姿态 | 连续高维 | 平衡(+)、跌倒(-) |
| 扫地机器人 | 房间布局、电量 | 离散 | 清洁面积(+)、电量耗尽(-) |
| 国际象棋大师 | 棋盘、时间 | 离散有限 | 赢(+1)、输(-1) |
| 客服 Agent | 对话历史、知识库 | 变长组合式 | 问题解决(+)、时间(-) |
| 代码助手 | 需求、代码库 | 变长组合式 | 测试通过(+)、引入 bug(-) |

棋类与 Atari 使用预定义有限离散动作；机器人控制用有界连续动作；LLM Agent 用有限 token 与工具 schema 组合出**变长动作序列**，很难一次枚举，并且可以利用「内部思考」。

## 2. MDP 与 Q-learning

MDP 是 RL 的数学框架，核心假设是**马尔可夫性质**：未来只取决于当前状态，而当前状态必须包含决策所需的全部历史信息。

以国际象棋为例，状态不仅包括棋子位置，还应包括轮到哪方、王车易位权、吃过路兵权、五十步规则与重复局面判定所需信息。状态定义充分时，无需每次重读完整棋谱。

![配图](https://raw.githubusercontent.com/swpucwf/MyBolgImage/main/img/aiagent_fig8-2.svg)

<p>图 2：马尔可夫决策过程示意</p>

典型 RL 环境使用**预先定义的动作空间**：围棋 361 个落子位置虽大但有限；国际象棋可枚举；Atari 通常只有几个到十几个离散动作。机器人使用连续但有界的动作空间。

有限离散动作便于逐一评估候选；状态与动作数足够小时，表格 Q-learning 可以直接存储价值；更大状态空间需要函数近似与搜索。

Q-learning 为每个「状态—动作」维护价值估计：在状态 s 下采取动作 a、之后按最优策略行动，总共能拿多少奖励？

贝尔曼方程的核心递归：

\[
Q^*(s,a)=r+\gamma\max_{a'}Q^*(s',a')
\]

其中 r 是即时奖励，s' 是下一状态，γ∈[0,1) 是折扣因子——越接近 1 越重视长期回报。

算法每次行动后，把旧估计往「实际发生的结果」方向微调一点，这叫**时序差分学习**。经过成千上万次试错，估计逐渐逼近真实值。

![配图](https://raw.githubusercontent.com/swpucwf/MyBolgImage/main/img/aiagent_fig8-3.svg)

<p>图 3：Q-learning 网格世界</p>

![配图](https://raw.githubusercontent.com/swpucwf/MyBolgImage/main/img/aiagent_fig8-4.svg)

<p>图 4：Q 值更新可视化</p>

Q-learning 是**离轨策略**：可以用不同于目标策略的探索数据学习最优策略，但仍要求充分覆盖相关状态—动作对，并满足学习率与收敛条件——它不是对任意数据分布都能自动收敛。

一个寻宝实验很能说明它的特征：环境包含隐藏机制（钥匙与门、武器效果、合成规则）、多步依赖（最优 11 步）与稀疏奖励。Q-learning 前 1000 局 0% 胜率，5000 局仍无稳定胜利，7000–8000 局胜率从 34% 升到 96%，10000 局才 100% 并找到 11 步最优解。

训练只需不到 10 秒，但需要近 10000 次完整尝试。仿真里代价可忽略；真实 Agent 场景中，每次电话有成本、每次浏览器操作有延迟、每次错误可能不可逆——10000 次试错完全不可接受。

## 3. LLM 的变长动作空间

基于预训练 LLM 的 Agent，在动作表示与初始化方式上带来了重要变化。

经典 RL 也可以把内部计算建模为状态与动作；LLM 的实用变化不是第一次允许「思考」，而是预训练语言策略能用**变长 token 序列**表示内部计算，并与外部行动由同一策略生成。

最关键的是把**思考 token 作为特殊动作**纳入策略输出空间：它不直接改变外部环境，也不立即获得环境奖励，但能表达多种计算路径。于是动作空间不仅包括「做什么」，还包括「想多久、想什么」。

这种变长组合动作比原始动作搜索空间大得多，很难在没有先验时从零学习。LLM 从海量文本中学到了人类的问题解决模式——数学常按「识别条件→回忆公式→逐步计算」，编程常按「理解需求→设计结构→实现细节」。预训练给结构化路径更高先验概率，显著压缩搜索空间。

![配图](https://raw.githubusercontent.com/swpucwf/MyBolgImage/main/img/aiagent_fig8-5.svg)

<p>图 5：经典 RL 与现代 LLM Agent 对比</p>

因此即使没有额外 RL，预训练 LLM 也能生成基本思维链——这些模式来自数学解题、代码注释、讨论回应等语料，模型通过预测下一个 token 隐式学会「下一步思考应该长什么样」。

RL 后训练再用外部奖励教会模型在特定任务中更有效地利用这些模式。语言结构不是单独的「内部奖励」，而是预训练策略的**先验分布**：训练语料中常见的「换算外币先查汇率」初始概率较高，「换算货币先查天气」概率较低；RL 在这个分布上用真实奖励重新调整各路径概率。

![配图](https://raw.githubusercontent.com/swpucwf/MyBolgImage/main/img/aiagent_fig8-6.svg)

<p>图 6：OpenAI 训练范式演进</p>

姚顺雨在《The Second Half》中回顾了 OpenAI 的认知演变：

- **2015–2016 算法中心主义**：相信更好的算法是关键，Atari 等环境有进展，但换环境就得从头训练；
- **2016–2018 环境的重要性**：Gym 标准化任务，Universe/World of Bits 想把互联网变成 RL 环境，Dota 2 追求超人表现；但通用计算机使用与网页导航始终无法突破；
- **2018 至今 先验的觉醒**：GPT-2/3 展示语言预训练的力量，WebGPT/ChatGPT 证明先验能转化为实用 Agent。最重要的发现是：**先验知识可以通过与 RL 完全无关的方式获得。**

这带来一个反直觉的优先级：不是算法 > 环境 > 先验，而是**先验 > 环境 > 算法**。

### 3.1 寻宝游戏里的对照

![配图](https://raw.githubusercontent.com/swpucwf/MyBolgImage/main/img/aiagent_fig8-7.svg)

<p>图 7：Q-learning 与 LLM Agent 在寻宝游戏中的架构对比</p>

同一个寻宝游戏，LLM Agent（Kimi K3，维护最多 50 条经验缓冲区）**第一局 18 步通关**。

- **前期有目的探索**：拿起生锈的剑（「武器总比空手好」），系统探索地图，发现北门被锁后推理「需要找钥匙」，转而探索储藏室，取得红钥匙与魔法水晶；
- **中期机制理解**：理解「钥匙自动使用」规则，预判生锈的剑不足以对付守卫，第 8 步主动合成银剑；
- **后期执行与纠错**：持银剑向北，第 13 步击败强守卫，其间夹杂一两步无效尝试，最终第 18 步取得宝藏。

这展现了语义理解与符号映射的差异。LLM 理解游戏的概念结构，每步都有目的与逻辑；对 Q-learning 来说，「门」「钥匙」「剑」只是无意义符号，只能靠大量统计慢慢发现关系。

成本形成有趣悖论：Q-learning 跑 10000 局只需 10 秒，LLM 一局要 1–2 分钟。但现实任务中，每次交互的时间、金钱与风险成本远超纯计算，单看 GPU 时间并不公平。

更关键的洞察：**LLM Agent 的成功不是因为更好的学习算法，而是因为携带海量先验知识。** 游戏规则变化时，Q-learning 要完全重训，LLM 能通过推理直接适应。

设计原则因此是：仿真成本低、可大量重复的场景，传统 RL 仍有价值；交互成本高、需快速适应的现实场景，LLM 的样本效率更实际。

## 4. 预训练给了什么

![配图](https://raw.githubusercontent.com/swpucwf/MyBolgImage/main/img/aiagent_fig8-9.svg)

<p>图 8：视觉语言模型架构</p>

预训练的两个实验帮助建立直觉。

**从头训练小型 LLM**：以一亿参数模型为例，在消费级 GPU 完成完整流程。引入 QK Norm 与 Muon 优化器后，收敛速度提升 3 倍，总训练约 14 小时、成本约 34 美元。预训练后能回答事实性问题但格式不规范；SFT 后指令遵循与格式显著改善；偏好优化进一步减少事实错误。启示是：**固定小规模预算下，算法改进比单纯堆规模更具性价比。**

**训练 VLM**：视觉编码器（如 CLIP，参数固定）提取图像特征；投影层（轻量，唯一从头训练的部分）把视觉特征映射到语言模型空间；语言模型生成描述。训练采用「冻结 LLM + 只训练投影层」避免灾难性遗忘；对齐后再解冻 LLM，用高质量图文对做 SFT。

这揭示多模态训练的基本范式：复用单模态预训练成果，通过轻量投影层实现跨模态对齐——高效可扩展，但投影层表达能力有限，可能成为深层理解瓶颈。同样的「视觉编码器 + 投影层 + LLM」骨架再向前一步、让模型输出动作，就是 VLA。

两个实验共同说明：预训练赋予描述性知识与语言建模能力，缺乏结构化指令遵循与任务导向行为。但如果通用预训练没覆盖目标语言或领域，直接 SFT/RL 也绕不过缺口——这正是 Mid-training 要解决的。

## 5. 补记

经典 RL 与 LLM Agent 的差别，不只是动作空间大小，而是**先验从哪来**。表格 Q-learning 从零试错，样本效率极低；LLM 把人类的问题解决模式压缩进参数，第一步就有方向。

因此不要照搬经典 RL 的直觉：在 Agent 场景里，环境交互昂贵、不可逆，算法再精巧也无法弥补「从零探索」的代价。先验、环境与数据，优先级高于算法。
