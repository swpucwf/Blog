# 后训练：四阶段与 SFT/RL 的本质

## 1. 四阶段全景

Agent = LLM + 上下文 + 工具。本篇聚焦优化 LLM 这个「大脑」——通过改动权重，把能力沉淀进参数。

现代模型的能力开发通常拆成四个环节：

| 阶段 | 数据 | 优化目标 | 学到什么 | 代价 |
|---|---|---|---|---|
| 预训练 | 海量互联网文本 | 预测下一个词 | 语言规律、世界知识、基本推理 | 极高 |
| Mid-training | 目标语言/领域/能力语料 + 保留数据 | 继续预测下一个词 | 补齐领域知识、语言与基础能力 | 中到高 |
| SFT | 几千到几万条输入—输出示范 | 预测下一个词（只在回答上算损失） | 指令遵循、格式、风格、流程 | 低 |
| RL | 任务、环境 + 奖励信号 | 最大化期望奖励 | 可迁移策略、探索新解法 | 高（常是 SFT 的几十到上百倍） |

一个类比：预训练是通识教育，Mid-training 是集中研修专业教材，SFT 是老师示范答题与表达规范，RL 是自己下场做题、根据结果反复打磨。

两条主线贯穿全章：

- **SFT 记忆、RL 泛化**：在受控对照实验中，SFT 对训练答案过拟合，RL 在分布变化测试中更容易学到可迁移策略。这不是普遍属性——数据多样、正则化得当时 SFT 也能泛化；奖励或环境有偏时 RL 也会过拟合。
- **数据和环境比算法更重要**：掌握 PPO/GRPO 的基本用法即可，真正决定成败的是 Mid-training 语料、示范数据、仿真环境与奖励。很多场景下，前两类数据质量到位，甚至不需要 RL。

## 2. 预训练与 Mid-training

### 2.1 预训练：预测下一个词

现代大模型的全部「智能」，建立在一个简单任务上：**预测下一个词**。

给模型看一段文本的前半部分，让它猜下一个 token。输入「中国的首都是」，模型应给「北京」高概率。每猜一次，就把预测与真实 token 比较，差距（Loss）越大，越用力调整参数。在几万亿 token 上反复做，模型被迫学会语法、事实、逻辑与基本推理——要持续猜对，没有捷径。

关键点：**模型输出本质是一个概率分布**。给定前文，它对词表里每个 token 给出概率。训练就是调整这个分布——让想要的更高、不想要的更低。四个环节的区别，只在于「想要什么」以及「用什么信号定义想要」。

预训练之后，模型博学却不好用：问它问题，它可能续写出更多问题——因为互联网文本里，问题后面常跟着另一个问题。它还没学会「被提问时应该回答」这个协议。

### 2.2 Mid-training：在目标分布上继续学习

通用预训练不可能覆盖所有语言、领域与能力。如果模型读不懂韩语文档、不懂企业内部协议，或没有形成长上下文/代码表征，跳过这一步直接教「如何回答」或只按成败给奖惩，是补不上基础能力的。

Mid-training 沿用下一个 token 目标，但把数据分布收窄到目标领域，并混入通用保留数据控制遗忘。它回答的是「模型是否拥有完成任务所需的知识与基本能力」。

它与 SFT 的损失函数很像，但数据组织与监督密度不同：Mid-training 通常把整段文档、代码、推导都作为学习目标，对大量 token 算损失；SFT 把数据组织成输入—输出示范，通常只在回答 token 上算损失。用少量 QA SFT 让模型背一批事实并非不可能，但它只反复强化少数访问路径，容易记住问法而不形成广泛可调用的知识。

需要吸收大规模、相互关联的领域知识，优先 Mid-training；需要知识可更新、可追溯，优先 RAG。

## 3. SFT：换了数据的「预测下一个词」

这是第一个要打通的关键认知：**SFT 在数学上与预训练是同一个任务**——都是预测下一个词、最小化同一个损失函数。

差别只有两点：

1. **数据不同**：预训练用原始互联网文本；SFT 用人工准备的输入—输出对，格式统一为「用户提问 → 理想回答」。
2. **损失只算在回答上（loss masking）**：一条样本包含问题与标注回答，我们不希望模型学「怎么提问」，只希望学「怎么回答」，所以计算损失时屏蔽问题 token，只对回答回传梯度。

![配图](https://raw.githubusercontent.com/swpucwf/MyBolgImage/main/img/aiagent_fig8-10.svg)

<p>图 2：监督微调流水线</p>

这解释了 SFT 为什么在有限示范上表现记忆倾向：它的目标是让标注回答里每个 token 的概率尽可能高，也就是尽量复现示范。目标明确、格式固定的任务极其高效（几千条就见效）；数据覆盖与多样性不足时，可能对表面模式或捷径过拟合。

一句话：**SFT 用极高的样本效率，把一套稳定的「输入 → 输出」映射与协议固化进参数。** 它固化的是格式、风格、流程这类**协议性知识**，而非大量**事实性知识**——后者靠预训练或 RAG。

> **训练成本：LoRA**。全参微调要为数亿到数十亿参数存梯度与优化器状态。LoRA 不动原权重，只在旁边挂一个低秩「补丁」，参数量仅 1%–5%，却能接近全参效果；原权重冻结，对基座能力扰动更小，遗忘风险更低。经验：要应用到所有主要权重矩阵（尤其 MLP 层），只加注意力层会掉点；最优学习率约是全参的 10 倍；SFT 用中高 rank（64–256），RL 因每轮信息少，小 rank（8–32）甚至 1 就够。部署时一台服务器可加载多个 adapter 做多租户。

## 4. 何时需要先补底座

RL 用奖励评估模型**自己生成**的回答，而不是直接模仿参考答案。要从这种信号学习，至少两个前提：输出可验证，且当前策略偶尔能探索到有价值行为。

**格式支持**：任务要求 JSON 或工具调用，模型却吐出无法解析的文本，奖励函数连成败都判不了。此时 SFT 先稳定格式与基本流程，使奖励可计算，再由 RL 优化策略——这就是「先 SFT、后 RL」。

**能力支持**：在留出任务上以训练相近温度采样，测 pass@1 与 pass@k。若 p 为单次成功率：

\[
\mathrm{pass@}k=1-(1-p)^k
\]

pass@1 低但 pass@k 随 k 明显上升，说明正确策略已在分布里，只是概率质量太小，RL、拒绝采样或蒸馏都有东西可放大。

若在合理 k、温度与任务覆盖下 pass@k 仍接近 0，基模几乎生成不出成功轨迹。只给终点 0/1 奖励时，GRPO 一组 rollout 很可能全为 0，组内优势消失；PPO 也看不到该往哪移动的正向样本。

这时先问缺什么：缺领域语言、事实、代码模式或长上下文，优先 Mid-training 补底座；已有能力但不会按接口表达，先用 SFT；能局部前进但到不了终点，加入可验证部分奖励或课程学习。

**RL 擅长把已有但概率较低的成功行为推高，不擅长从全零奖励中凭空创造模型从未学过的知识。**

一个边界：「必须先 SFT」只在格式或基本行为尚未建立时成立。足够强、已有非零成功率的基模可以跳过 SFT——DeepSeek-R1-Zero 就是这种情形；后来加入冷启动 SFT，主要是改善可读性与语言一致性，不是注入任务知识。

## 5. SFT 与 RL 的本质区别

![配图](https://raw.githubusercontent.com/swpucwf/MyBolgImage/main/img/aiagent_fig8-11.svg)

<p>图 3：SFT → RL 两阶段流程；Mid-training 位于两者之前</p>

- **SFT 最大化标注回答的概率**：每个样本用极大似然推动模型复现示范。示范多样时可学到可泛化特征；不足时可能对表面模式过拟合。GeneralPoints 的有限示范把 J/Q/K 都当 10，测试值变化时性能下降。
- **RL 最大化期望奖励**：模型探索多条路径，提高高奖励路径的概率。奖励忠实、探索足够时，可能发现示范外的可迁移策略——GeneralPoints 中重新执行计算过程而不是套固定值，在分布外表现更好。奖励或环境有偏时，同样可能过拟合捷径。

| 维度 | SFT | RL |
|---|---|---|
| 优化目标 | 最大化标注答案概率 | 最大化期望奖励 |
| 信号 | 逐 token 监督 | 轨迹 + 结果/步骤级标量奖励 |
| 数据 | 输入—输出示范 | 任务、环境 + 奖励 |
| 分布漂移 | 取决于示范覆盖与正则化 | 取决于奖励、环境与探索 |
| 样本效率 | 高（几千条见效） | 低（几十到上百倍） |
| 稳定性 | 高、收敛快 | 低、易震荡 |
| 最适合 | 固化格式/风格/流程 | 泛化到新场景、探索最优策略 |

从概率分布看，一个问题常存在多类合理回答，每类对应一个「峰」。极大似然 SFT 常表现 **mass-covering**：尽量覆盖示范中的多个模式。RL 按奖励重新分配概率，配合反向 KL 约束时更易表现 **mode-seeking**：把概率集中到少数高奖励峰上。

SFT 擅长覆盖多种已知写法，RL 擅长从候选中寻找高奖励策略；最终是保持多样性还是收缩到少数模式，取决于示范分布、奖励、KL 方向与系数、熵正则与采样温度。

### 5.1 后训练也塑造「何时行动」

Coding 模型中，不同模型有不同默认行动阈值：有的先读更多仓库信息再修改，有的用较少文件快速定位、先实现再借测试反馈修正。

这不是拟人化成「谨慎」或「有直觉」，而是参数中的策略在估计：多读一个文件的预期价值，是否高于提交当前补丁并验证的预期价值。

若 SFT 示范反复包含广泛调查后才编辑，模型会模仿较高阈值；若 RL 的过程或结果奖励持续认可快速定位、尽早进入可验证循环，概率质量就会向较早行动集中。Harness 可以调节，但行为的主要来源可以位于后训练后的参数中。

### 5.2 在线反馈的三个机会

固定数据上的 SFT 使用示范的直接信号，但仍可组合预训练知识泛化。在线 RL 让模型按当前策略生成、接收环境反馈，直接评估示范之外的候选。三个机会：

- **评估示范外的候选**：SimpleVLA-RL 中的「推切」动作从未出现在人类示范中。但奖励无法识别的质量学不到，探索不到的策略也发现不了。
- **利用「验证比生成容易」**：SFT 要先写出正确答案；RL 只需可靠判断答案质量。数学可对照、代码可测试、定理可由验证器检查。这种不对称是 RLVR 的优势，但验证器不完整时也会导致奖励黑客。
- **在当前策略实际访问的状态上训练**：离线模仿有协变量漂移——策略偏离示范、进入数据中没有的状态后，可能缺少恢复信号。在线数据聚合能把误差累积从约 \(T^2\) 降到约 \(T\)。

打个比方：**SFT 细致学习已有地图，RL 拿着奖励这枚指南针探索地图外的候选路线。** 地图或指南针不准都会迷路。因此许多系统先用 SFT 建立稳定起点，再在奖励与环境可信时加入 RL。

## 6. 补记

四阶段不是「三种微调力度」，而是分别处理**底座、协议与策略**：Mid-training 补知识与基础能力，SFT 固格式与流程，RL 重新分配概率并探索新路径。

最重要的判断不是「上哪个算法」，而是「缺的到底是哪一层」。pass@k 近零先补底座；会做但输出不可解析先 SFT；有非零成功率且奖励可靠，才轮到 RL。
