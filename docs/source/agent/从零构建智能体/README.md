# 从零构建智能体

从「智能体是什么」讲起，先理清传统智能体到 LLM 驱动的演进、任务环境与运行循环，再落到可执行的构建路径：ReAct 等经典范式、自研框架的接口与工具系统、记忆与 RAG、上下文工程、MCP/A2A/ANP 通信协议，最后是智能体性能评估。侧重框架内部怎么实现，原理部分的细枝末节留给相邻系列。

> 内容整理自开源教程 [datawhalechina/hello-agents](https://github.com/datawhalechina/hello-agents)，作为参考笔记。
