# 智能体发展史

现在的智能体架构不是设计出来的最优解，而是几轮失败之后剩下的交集。符号主义给出了推理框架却卡在知识获取，联结主义解决了感知却不会决策，强化学习补上决策却缺少先验知识，预训练补上知识之后，三者在同一套循环里合流。

## 1. 一条被问题推动的路线

每个新范式的出现，都是为了解决上一代的核心痛点；而它带来的能力飞跃，又制造了当时难以克服的新局限。看清这条「问题—方案—新问题」的链条，比记住年代更有用，因为它解释了现代智能体为何长成现在的样子。

## 2. 符号主义：智能即符号计算

早期 AI 的信念很直接：人类智能尤其是逻辑推理，可以被形式化的符号体系捕获。智能体被看作一个**物理符号系统**——用内部符号表示外部世界，用逻辑推理规划行动，「智慧」完全来自设计者预先编码的知识库与推理规则。

1976 年纽厄尔与西蒙的**物理符号系统假说（PSSH）**给了它理论地位，两个论断：物理符号系统具备产生通用智能的充分手段；任何展现通用智能的系统，本质必然是物理符号系统。一句话，智能的本质就是符号的计算与处理。

**专家系统**是这一代最成功的产物。架构上把知识与推理分开：

- **知识库**：领域知识，最常用**产生式规则**（IF-THEN），如 `IF 发烧 AND 咳嗽 THEN 呼吸道感染`。大型系统有上千条规则，构成庞大的知识网络。
- **推理机**：通用程序，按事实匹配规则。正向链从事实推结论（数据驱动），反向链从假设找证据（目标驱动）。

MYCIN 是标志性案例：1970 年代斯坦福开发，用于细菌性血液感染诊断与抗生素推荐，约 600 条规则，主要走反向链——从「确定致病菌」出发倒推需要哪些证据，再向医生提问。它的创新是**置信因子（CF，取值 -1 到 1）**，让系统能表达「可能」「很可能」，而不是非真即假的布尔判断。评估中它的表现超过非专业医生。

**SHRDLU** 则展示了另一种野心：在积木世界这个封闭微环境里，把自然语言理解、规划、记忆集成到一个系统中。它要处理指代消解（`the one you are holding`）、上下文记忆、动作序列规划（目标位置被占则先搬开），还能回答「为什么拿起红色积木」这类动机问题。它的价值在于首次跑通「感知—思考—行动」闭环，也第一次让人看到：闭环成立依赖环境足够封闭。

## 3. 符号主义的两个硬伤

走出微观世界，符号主义立刻遇到两类问题。

**知识层面**：专家知识要靠知识工程师访谈、提炼、编码，成本高、周期长、难规模化，且大量专家知识是内隐的；这就是**知识获取瓶颈**。更麻烦的是**常识**——「水是湿的」「绳子能拉不能推」这类背景，系统不显式编码就一无所知，而 Cyc 项目耗数十年仍收效有限。

**逻辑层面**：**框架问题**——动作执行后如何高效判断哪些事物没变，为每个动作显式声明所有不变状态在计算上不可行，人却能毫不费力地忽略无关变化。以及**脆弱性**——遇到规则外的微小变化就整体失灵，SHRDLU 的成功正因为它活在规则完备的封闭世界里。

## 4. 规则驱动的对话：ELIZA

1966 年魏泽鲍姆发布的 ELIZA 是这套思路在对话上的极端例子。它并非要「理解」情感，恰恰相反，作者想证明：只靠句式转换，机器就能在完全不理解内容的情况下营造共情假象。结果超出预期——包括秘书在内的许多用户对它产生了情感依赖，这就是后来的 **ELIZA 效应**。

最成功的脚本 DOCTOR 模仿罗杰斯学派治疗师，策略是「从不正面回答，把陈述转成开放式提问」。算法只有四步：

1. **关键词识别与排序**：规则库给每个关键词设优先级，命中多个时取最高。
2. **分解**：用带通配符的模式捕获剩余部分，`* my *` 匹配 `My mother is afraid of me`，捕获 `mother is afraid of me`。
3. **重组**：从关联模板里随机选一条生成回应，增加多样性。
4. **代词转换**：`I → you`、`my → your`，维持对话连贯。

```python
rules = {
    r'I need (.*)':        ["Why do you need {0}?", "Would it really help you to get {0}?"],
    r'I am (.*)':          ["How long have you been {0}?", "How do you feel about being {0}?"],
    r'.* mother .*':       ["Tell me more about your mother.", "How do you feel about your mother?"],
    r'.*':                 ["Please tell me more.", "Can you elaborate on that?"],
}

def respond(user_input):
    for pattern, replies in rules.items():          # 按插入顺序，等于优先级
        m = re.search(pattern, user_input, re.IGNORECASE)
        if m:
            captured = swap_pronouns(m.group(1) if m.groups() else '')
            return random.choice(replies).format(captured)
```

跑起来很像那么回事，但三个局限立刻暴露：面对 `I am not happy` 仍会匹配 `I am (.*)`，因为它不理解否定；系统无状态，每次只看当前单句；规则库增长的边际成本极高，规则冲突与优先级管理会迅速失控。看似智能的表现，完全依赖预先编码的规则——这就是脆弱性的根源。

## 5. 心智社会：从单体到群体

明斯基没有继续给单一推理核心加规则，而是换了个问题。他的判断是：智能的力量来自**巨大的多样性**，而不是某个单一完美原则。于是提出**心智社会**——心智不是金字塔，而是扁平的社会。

这里的「智能体」是极简单、专门化、本身「无心」的心智过程，比如只负责识别线条的 `LINE-FINDER`、只负责抓握的 `GRASP`。它们被组织成**机构（Agency）**，机构之间通过去中心化的激活与抑制信号互相影响。**涌现**是关键：复杂有目的的行为不是被某个高层预先规划，而是从大量简单单元的局部交互中自发产生。

搭积木塔的例子很清楚：`BUILD-TOWER` 不知道物理动作，只激活 `BUILDER`；`BUILDER` 只做「塔没搭完就激活 `ADD-BLOCK`」的循环；`ADD-BLOCK` 依次激活 `FIND-BLOCK`、`GET-BLOCK`、`PUT-ON-TOP`；`GET-BLOCK` 再激活视觉的 `SEE-SHAPE` 与运动的 `REACH`、`GRASP`。没有任何单元拥有全局规划，塔却搭起来了。

这个理论给后来的多智能体系统留下三条线索：**去中心化控制**（没有中心节点时如何协调与分配任务）、**涌现式计算**（蚁群、粒子群这类从局部规则得到全局解的方法）、**智能体的社会性**（通信语言、交互协议、协商、信任、组织结构）。

## 6. 学习范式：从联结到预训练

如果智能无法被完全设计，那能否被学习出来？这条追问串起了后面三条路线。

**联结主义**是自下而上的回应：知识不是规则，而是连接权重，分布式地存在大量简单单元之间；单元只做加权输入加激活函数；智能来自用样本迭代调整权重（反向传播）。它解决了感知，却没解决决策。

**强化学习**专攻序贯决策：智能体、环境、状态、行动、奖励五要素，策略把状态映射到行动，目标是最大化**累积奖励**而非即时奖励——「弃子」就是牺牲当下换未来。AlphaGo 的自我对弈是典型：观察棋盘，落子，一局结束按胜负得到 ±1 奖励，数百万局后策略自己收敛，不依赖人类棋谱。

**预训练**补上了先验知识。范式分两步：先在互联网级语料上自监督学习（常是预测下一个词），学到语言规律、事实与上下文逻辑；再针对下游任务用少量标注数据微调。规模跨过阈值后出现了未被直接训练的**涌现能力**——上下文学习（few-shot 甚至 zero-shot）与思维链推理。到这一步，LLM 同时具备了知识库与通用推理引擎两个身份。

## 7. LLM 智能体的模块化架构

历史拼图在这里合上：符号主义给逻辑框架，联结主义与强化学习给感知与决策，预训练给世界知识。现代 LLM 智能体把它们装进一个循环：

- **感知模块**：从环境取原始输入，形成观察。
- **规划模块 + LLM**：规划模块做策略制定与任务分解，借反思、自我批判把宏观目标拆细；LLM 结合**记忆模块**推理，产出下一步操作，通常是一次工具调用。
- **执行模块**：解析工具调用，从工具箱里选工具执行，改变环境状态。
- **回灌**：工具结果与新的环境状态共同构成下一轮观察，同时更新记忆。

## 8. 三条思潮与一张技术栈

主线其实只有三条，彼此竞争又互相借用：

| 思潮 | 核心主张 | 代表 |
| --- | --- | --- |
| 符号主义 | 智能是对符号的操作与逻辑推理 | SHRDLU、专家系统、深蓝 |
| 联结主义 | 智能是网络权重对数据的拟合 | CNN、Transformer |
| 行为主义 | 智能来自与环境交互试错 | TD-Gammon、AlphaGo、RL |
