# 快速上手：第一个 Deep Agent

## 1. 安装与配置

Deep Agents 以独立 Python 包发布，示例通过 `ChatOpenAI` 接入模型，因此同时安装 `langchain-openai`（Python 3.11+）：

```bash
pip install deepagents langchain-openai
# 或
uv pip install deepagents langchain-openai
```

推荐用硅基流动作模型提供商：国内直连、兼容 OpenAI 接口、有多款适合学习的模型、可选择 Qwen/DeepSeek/GLM 等。注册后在 API 密钥页创建 Key：

```bash
export SILICONFLOW_API_KEY="your-siliconflow-key"
export MODEL_NAME="Qwen/Qwen2.5-7B-Instruct"   # 当前适合学习的模型
```

> 轻量模型适合入门；任务规划、上下文总结、多子 Agent 编排等复杂场景，小模型往往跑不稳，建议换 `zai-org/GLM-5.2` 等能力更强、支持工具调用的模型。平台模型与免费范围会调整，用 `MODEL_NAME` 统一管理。

## 2. Hello World

```python
import os
from langchain_openai import ChatOpenAI
from deepagents import create_deep_agent

model = ChatOpenAI(
    model=os.environ.get("MODEL_NAME", "Qwen/Qwen2.5-7B-Instruct"),
    api_key=os.environ["SILICONFLOW_API_KEY"],
    base_url="https://api.siliconflow.cn/v1",
)

def get_weather(city: str) -> str:
    """Get weather for a given city."""
    return f"It's always sunny in {city}!"

agent = create_deep_agent(
    model=model,
    tools=[get_weather],
    system_prompt="You are a helpful assistant.",
)

result = agent.invoke(
    {"messages": [{"role": "user", "content": "北京今天天气怎么样？"}]}
)
print(result["messages"][-1].content)
```

几行代码就跑起了一个有工具调用能力的 Agent。

**`create_deep_agent()` 的核心参数**：

| 参数 | 说明 | 默认值 |
|---|---|---|
| `model` | 模型实例（如 `ChatOpenAI`）或 `provider:model_name` 字符串 | `claude-sonnet-4-6`（可覆盖） |
| `tools` | 自定义工具函数列表 | `[]` |
| `system_prompt` | 定义角色与行为 | v0.7 默认基础提示词为空 |

除了传入的工具，Deep Agent 还会提供文件系统、子 Agent 等 Harness 能力。**v0.7 不再默认启用任务规划**：需要 `write_todos` 时显式加入 `TodoListMiddleware`——短任务不为计划工具和提示词支付固定成本，长任务主动选择这层脚手架。

**`invoke()` 的输入输出**：输入是 `{"messages": [{"role": "user", "content": "..."}]}`；输出也是字典，`result["messages"]` 是完整对话历史，最后一条即最终回复。

## 3. 自定义工具：三个要素

Deep Agents 的工具定义很简单——**一个普通 Python 函数就是一个工具**，Agent 通过函数签名（参数名与类型标注）和 docstring 理解它。

```python
def internet_search(
    query: str,                          # 1. 参数名 + 类型标注
    max_results: int = 5,
    topic: Literal["general", "news", "finance"] = "general",
) -> dict:                               # 2. 返回类型
    """Run a web search for the given query."""  # 3. Docstring
    return tavily_client.search(query, max_results=max_results, topic=topic)
```

| 要素 | 作用 | 缺失的后果 |
|---|---|---|
| 参数类型标注 | 告诉 Agent 每个参数的类型 | 可能传入错误类型 |
| Docstring | 告诉 Agent 工具用途 | 不知道何时该用 |
| 默认值 | 标记可选参数 | 必填项过多，出错概率上升 |

> docstring 就是给 Agent 看的「使用说明书」，写得越清楚，用得越准确。

### 3.1 练手：计算器 Agent

先写两个不依赖外部 API 的工具，把注意力放在设计上：

```python
def calculate(expression: str) -> float:
    """Evaluate a math expression and return the result.

    Args:
        expression: A math expression, e.g. "1 + 2 * 3".
    """
    # 仅做演示，实际项目应使用安全的解析库而非 eval
    return eval(expression)

def convert_currency(amount: float, from_currency: str, to_currency: str = "CNY") -> dict:
    """Convert an amount from one currency to another.

    Args:
        amount: The amount to convert.
        from_currency: The source currency code, e.g. "USD".
        to_currency: The target currency code, defaults to "CNY".
    """
    rates = {"USD": 7.2, "CNY": 1.0, "EUR": 7.8}
    cny = amount * rates[from_currency]
    return {"amount": round(cny / rates[to_currency], 2), "currency": to_currency}

agent = create_deep_agent(
    model=model,
    tools=[calculate, convert_currency],
    system_prompt="你是一个计算助手，能帮用户做数学运算和货币换算。",
)

result = agent.invoke(
    {"messages": [{"role": "user", "content": "帮我把 100 美元换算成人民币，再用它乘以 1.08 的通胀系数。"}]}
)
```

`calculate` 用字符串承接整个表达式（标注告诉 Agent 传文本而非数字）；`convert_currency` 的 `to_currency` 有默认值，只换算人民币时只需填前两个参数——这就是三要素在实际设计中的体现。

## 4. 实战：研究助手

### 4.1 依赖与工具

Tavily 作搜索 API（免费计划每月 1000 Credits），硅基流动作模型：

```bash
pip install deepagents langchain-openai tavily-python
export SILICONFLOW_API_KEY="your-siliconflow-key"
export TAVILY_API_KEY="your-tavily-key"
```

```python
import os
from typing import Literal
from tavily import TavilyClient

tavily_client = TavilyClient(api_key=os.environ["TAVILY_API_KEY"])

def internet_search(
    query: str,
    max_results: int = 5,
    topic: Literal["general", "news", "finance"] = "general",
    include_raw_content: bool = False,
):
    """Run a web search for the given query.

    Args:
        query: The search query string.
        max_results: Maximum number of results to return.
        topic: The topic category for the search.
        include_raw_content: Whether to include raw page content.
    """
    return tavily_client.search(
        query,
        max_results=max_results,
        include_raw_content=include_raw_content,
        topic=topic,
    )
```

### 4.2 创建 Agent

```python
from langchain_openai import ChatOpenAI
from deepagents import create_deep_agent
from langchain.agents.middleware import TodoListMiddleware

model = ChatOpenAI(
    model=os.environ.get("MODEL_NAME", "Qwen/Qwen2.5-7B-Instruct"),
    api_key=os.environ["SILICONFLOW_API_KEY"],
    base_url="https://api.siliconflow.cn/v1",
)

research_instructions = """你是一位专业的研究员。
你的工作是进行深入研究，然后撰写一份完整的研究报告。

你可以使用 internet_search 工具搜索互联网获取信息。
"""

agent = create_deep_agent(
    model=model,
    tools=[internet_search],
    system_prompt=research_instructions,
    middleware=[TodoListMiddleware()],
)
```

系统提示词只需说明研究目标、证据要求与输出边界。`internet_search` 的参数与接口已由工具 Schema 表达，不必再复制一遍通用教程；只有业务确实要求特定调用顺序或来源范围时，才补充规则。

```python
result = agent.invoke(
    {"messages": [{"role": "user", "content": "什么是 LangGraph？"}]}
)
print(result["messages"][-1].content)
```

## 5. 一次 `invoke()` 背后发生了什么

调用后执行的是一个**模型—工具循环**：模型收到当前上下文，决定调用工具还是直接回答；工具结果写回上下文，再交给模型决定下一步。

https://raw.githubusercontent.com/swpucwf/MyBolgImage/main/img/deepagents_05-flowchart-agent-loop.svg

<p>图 1：Deep Agent 核心执行循环</p>

Middleware 让循环具备 Harness 能力：模型调用前可整理上下文、注入技能索引或记忆；工具执行阶段可检查权限、等待审批、处理大体积结果；技能正文仍由模型按需 `read_file` 读取。不同 Middleware 使用不同 hooks，图中能力框表示介入位置，不表示每轮都执行全部操作。

文件读写、计划维护、子任务委派，都是循环里可选择的工具动作：

- 模型选择 `internet_search` → 执行应用注册的搜索工具；
- 模型选择 `read_file` → 执行内置文件工具，通过 Backend 读内容；
- 模型选择 `task` → 主 Agent 把任务交给子 Agent，子 Agent 用独立上下文运行后返回结果；
- 配置了人工审批 → 相关调用暂停，提交决定后从中断处继续（第 10 篇展开）。

正常完成时，模型不再请求工具，生成最终回复；异常或达到运行限制也可能提前结束；触发审批中断则等待恢复。**`invoke()` 不意味着底层只调用一次模型。**

研究任务的一种可能路径：

1. **规划任务**：示例显式启用了 `TodoListMiddleware`，Agent 可调用 `write_todos` 把「研究 LangGraph」拆成子步骤；
2. **搜索信息**：多次调用 `internet_search`；
3. **管理上下文**：调用内置 `write_file` 把大量搜索结果写入虚拟文件系统，避免上下文溢出；
4. **委派子任务**（如需要）：调用 `task` 交给专门子 Agent；
5. **综合报告**：从文件系统读回整理好的信息，撰写报告。

过程中可能调用 10+ 次工具，但只需要一次 `invoke()`。实际顺序、次数与是否委派取决于任务、模型决策与启用的能力。

https://raw.githubusercontent.com/swpucwf/MyBolgImage/main/img/deepagents_05-flowchart-agent-workflow.png

<p>图 2：一次调用背后的规划、搜索、上下文管理与综合</p>

> **v0.7 提醒**：图中的规划流程对应「已启用 Todo」的复杂研究任务。没有传 `TodoListMiddleware` 时，Agent 不会获得 `write_todos` 和 `todos` 状态；即使启用，模型也会根据任务决定是否实际调用——不能把图中每一步当成固定执行协议。

## 6. 模型选择

Deep Agents 支持任何实现工具调用（Tool Calling）的 LangChain Chat Model。行业已形成两种事实标准接口：

- **OpenAI 兼容**（`/chat/completions`）：采用最广，国内外多数平台兼容；
- **Anthropic 兼容**（`/messages`）：Anthropic 原生协议，部分平台也提供。

硅基流动同时支持两种，可用 `ChatOpenAI` 或 `ChatAnthropic` 接入同一平台上的模型。

https://raw.githubusercontent.com/swpucwf/MyBolgImage/main/img/deepagents_06-comparison-api-interfaces.png

<p>图 3：两种标准接口对比</p>

**方式一：OpenAI 兼容（推荐）**

```python
model = ChatOpenAI(
    model="Qwen/Qwen2.5-7B-Instruct",
    api_key=os.environ["SILICONFLOW_API_KEY"],
    base_url="https://api.siliconflow.cn/v1",
)
agent = create_deep_agent(model=model)
```

换 URL 与 Key 即可切到 DeepSeek、智谱、阿里云等平台。

**方式二：Anthropic 兼容**

```python
from langchain_anthropic import ChatAnthropic

model = ChatAnthropic(
    model="zai-org/GLM-5.2",
    api_key=os.environ["SILICONFLOW_API_KEY"],
    base_url="https://api.siliconflow.cn",
)
```

**方式三：字符串格式（原生平台直连）**

```python
agent = create_deep_agent(model="anthropic:claude-sonnet-4-6")  # 需 ANTHROPIC_API_KEY
agent = create_deep_agent(model="openai:gpt-4.1")               # 需 OPENAI_API_KEY
```

选模型的原则：**简单试跑用轻量模型，任务规划/上下文总结/多 Agent 编排换更强模型**。小模型在叠加中间件后往往无法稳定跑通完整流程，这是后面章节反复会遇到的前提。

## 7. 调试与追踪：LangSmith

Agent 行为不符合预期时，需要看到它「内部在想什么」。LangSmith 记录每次模型调用、工具调用与状态变化。启用时在 `.env` 配置：

```dotenv
LANGSMITH_TRACING=true
LANGSMITH_API_KEY=your-langsmith-key
LANGSMITH_PROJECT=deepagents-course
LANGSMITH_ENDPOINT=https://api.smith.langchain.com
```

**区域要对应**（不设置时默认 GCP US）：

| 数据区域 | 控制台 | Endpoint |
|---|---|---|
| GCP US（默认） | smith.langchain.com | `https://api.smith.langchain.com` |
| GCP EU | eu.smith.langchain.com | `https://eu.api.smith.langchain.com` |
| GCP APAC | apac.smith.langchain.com | `https://apac.api.smith.langchain.com` |

`.env` 需要由启动工具或代码加载，直接跑 Python 脚本不会自动读取。macOS/Linux/WSL2 可在项目根目录执行：

```bash
set -a
source .env
set +a
```

修改 `.env` 后要重新加载并从新终端启动；已运行进程需重启。配置生效后，进入对应区域的 `deepagents-course` 项目查看 Trace——决策链路、工具参数与返回值、子 Agent 执行、每步 token 与耗时、虚拟文件系统里的文件变化都能看到。

如果 Agent 正常回答但 Trace 没出现，或上传报 401/403：先核对区域、Key 与进程是否加载了新变量，再检查项目名与 Key 权限；Key 可访问多个 Workspace 时还要设置 `LANGSMITH_WORKSPACE_ID`。

## 8. 完整代码（精简版）

```python
import os
from typing import Literal
from langchain_openai import ChatOpenAI
from tavily import TavilyClient
from deepagents import create_deep_agent

model = ChatOpenAI(
    model=os.environ.get("MODEL_NAME", "Qwen/Qwen2.5-7B-Instruct"),
    api_key=os.environ["SILICONFLOW_API_KEY"],
    base_url="https://api.siliconflow.cn/v1",
)
tavily_client = TavilyClient(api_key=os.environ["TAVILY_API_KEY"])

def internet_search(query: str, max_results: int = 5,
                    topic: Literal["general", "news", "finance"] = "general",
                    include_raw_content: bool = False):
    """Run a web search for the given query."""
    return tavily_client.search(query, max_results=max_results,
                                include_raw_content=include_raw_content, topic=topic)

agent = create_deep_agent(
    model=model,
    tools=[internet_search],
    system_prompt="你是一位专业的研究员，请搜索资料并撰写完整报告。",
)

result = agent.invoke({"messages": [{"role": "user", "content": "什么是 LangGraph？"}]})
print(result["messages"][-1].content)
```
