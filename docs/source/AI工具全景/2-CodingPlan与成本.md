# Coding Plan 与成本

## 1. 订阅与 API 是两条路

Coding Plan 是以固定月费提供模型调用能力的编程订阅套餐。它与按量计费的 API 并行存在：**订阅制适合高频、交互式编程，API 适合低频或批量调用**。

价格与档位变动很快，下面的刊例价仅作结构参考，下单前必须核对官方购买页。

## 2. 三种订阅形态

2026 年这一品类最大的变化不是价格，而是计费逻辑与产品名同时在重构：

| 形态 | 计费单位 | 代表 | 注意点 |
|---|---|---|---|
| Coding Plan（按次） | 每 5 小时 / 周 / 月的请求次数 | 阿里云 | 额度直观，但一次复杂任务可能吃掉 5～30 次 |
| Token Plan（按额度） | 积分 / Credits，按 token 折算 | 腾讯云、智谱、小米、MiniMax | 新主流，同一份额度可跑编程也可跑 Claw |
| 会员订阅（共享池） | 会员功能共享一个额度池 | Kimi | 编程只是权益之一，会与办公、Agent 抢额度 |

命名的迁移也在发生：腾讯云已把「通用 Token Plan」定为正式名，百度千帆、讯飞的产品也并入了 Token Plan。**看到「Coding Plan」不要默认它还是按请求次数计费**，先确认计费单位。

## 3. 主流套餐

| 套餐 | 厂商 | 入门价 | 覆盖模型 | 特点 |
|---|---|---|---|---|
| 方舟 Coding Plan | 火山引擎 | 40 元/月 | 豆包、GLM、Kimi、DeepSeek、MiniMax + Auto 路由 | 模型自由、工具不限；另有平行的 Agent Plan 线 |
| GLM Coding Plan | 智谱 AI | 118 元/月 | GLM-5.3 系列 | 积分制（周度），支持 20+ 工具，包季 8 折、包年 7 折 |
| Kimi 会员 | 月之暗面 | 49 元/月 | Kimi K3 / K2.7 Code | 已并入会员权益，四档均可调用，额度与全家桶共享 |
| MiniMax Token Plan | MiniMax | 49 元/月 | MiniMax 系列（含图像、语音） | 全模态共享额度，明确标注并发 Agent 数 |
| 阿里云 Coding Plan | 阿里云百炼 | 200 元/月（仅 Pro） | 千问 + Kimi / GLM / MiniMax | 按请求次数计费，工具兼容性最广；Lite 已停售 |
| 腾讯云 Token Plan | 腾讯云 | 28 元/月（Hy 线） | 混元专属线 / 多模型通用线 | 分两条独立产品线，各四档，不支持退款与降配 |

另有一批性价比取向的套餐：

- **小米 MiMo Token Plan**：39 元/月起，四档，非高峰时段消耗系数 0.8；
- **联通云元景 / 星罗**：15 元/月起，个人版与团队版分开（注意它另有独立的 Coding Plan，不是同一产品）；
- **华为云码道**：体验版 0 元永久免费（每月 500 积分），是目前少见的长期免费档；
- **摩尔线程 AI Coding Plan**：30 天免费试用，按季订阅；
- **讯飞 Astron**：199 元/月，此前的 19 元无忧版已下线；
- **OpenCode Go**（国际）：$10/月，聚合 30 款开源模型。

## 5. 多维对比

| 维度 | 方舟 | GLM | Kimi | MiniMax | 阿里云 | 腾讯云 |
|---|---|---|---|---|---|---|
| 入门价格 | 40 | 118 | 49 | 49 | 200（仅 Pro） | 28（Hy 线） |
| 计费单位 | 两档制 | 积分（周度） | 共享额度池 | token 额度 | 请求次数 | 积分 |
| 模型自由度 | 多模型 + 路由 | 仅 GLM | 仅 Kimi | 仅 MiniMax | 千问 + 第三方 | 混元线 / 通用线二选一 |
| 工具兼容 | 不限 | 20+ | 主流 CLI/IDE | 主流 CLI/IDE | 最广 | 含 Claw 类工具 |
| 退款 | — | — | — | — | 不支持 | 不支持 |

## 6. 按人画像选型

| 你是谁 | 推荐 | 理由 |
|---|---|---|
| 最低成本入门 | 联通云元景 / 腾讯云 Hy | 15～28 元档；华为云码道可先零成本试 |
| 日常编程要模型全 | 腾讯云通用 Token Plan | 一份额度覆盖 DeepSeek、GLM、Kimi、MiniMax |
| 习惯 Claude 系工具链 | GLM 或腾讯云通用线 | 注意：国产套餐只让你在 Claude Code 工具里跑国产模型，不提供 Claude 模型本身 |
| 只用 Kimi | Kimi 会员 | 四档均可调用，附带全家桶 |
| 要模型自由 + 工具不限 | 方舟 | 灵活性最高，抓住折扣窗口更划算 |
| 重度并发 | MiniMax Max/Ultra、智谱 Pro | 明确标注并发数，额度倍数更高 |

一条实用路径：

1. 产物是纯代码，还是也要跑 Claw 与文档处理？后者优先 Token Plan（额度通用）。
2. 主用哪个工具？确认它在官方兼容列表内。
3. 模型要求？只用一家就选自有模型套餐；要随时切换就选通用线；必须用 Claude 模型则没有套餐能满足。
4. 预算区间：40 元以下、40～120 元、不限，各对应不同组合。

## 7. 五个趋势

- **从单一模型转向多模型聚合**：腾讯云、阿里云已支持第三方模型，方舟在同一个套餐里混装豆包与多家模型；智谱、Kimi 仍坚持自有模型。
- **「Coding Plan」品牌名被「Token Plan」取代**：按请求次数计费的旧形态正在退场，阿里云是坚持者。
- **积分制成为统一度量**：同一份额度可在文本、图像、语音、Agent 任务之间通兑。
- **价格分层而非普涨**：入门价持续下探（15/28/39 元），头部档位上移（最高已到千元级），「入门便宜、重度变贵」是主旋律。
- **企业与个人分轨**：方舟 ArkClaw、智谱、小米都推出团队席位或企业版。

## 8. 几个高频疑问

**Coding Plan 与 API 的区别**：前者订阅制、适合交互式编程，后者按量、适合批量与程序内调用。几乎所有套餐都禁止把套餐 Key 用于 API 自动化调用。

**能否同时订阅多个**：可以但通常没必要，腾讯云限制每个主账号最多两个（通用线 + Hy 线各一个）。

**额度用完怎么办**：各家差异很大——自动降速、可购买加油包、或直接停服（小米 MiMo）。部分套餐到期无法续费、余额不结转，订阅前要确认。

**为什么价格和网上不一样**：限时活动价、新客首月优惠、第三方比价站滞后三种原因，以官方页面为准。

**套餐里的「Claude」是 Claude 模型吗**：不是。多数标注指「支持在 Claude Code 工具中使用」，模型仍是套餐自己的。
