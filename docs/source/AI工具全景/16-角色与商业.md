# 角色与商业

工具与选型之外还有一层视角：AI 时代的人站在什么位置——一类岗位在爆发（FDE），一种公司形态在成型（OPC），而它们共同的计价单位是 Token。

## 1. FDE：前沿部署工程师

一句话：驻扎客户现场、亲手写代码、让 AI 在企业真实场景里跑起来的人。英文 Forward Deployed Engineer。

**为什么此刻爆发**。FDE 不是新概念，Palantir 在 2010 年代就设过这个岗位（早期内部称 Deltas，2016 年前 FDE 比软件工程师还多）。它现在爆发，直接原因是模型能力与落地能力之间的鸿沟：

- 买 AI 工具容易，把 AI 接进既有产线难；
- 客户工程师懂业务但不懂模型在规模下的行为，模型公司工程师懂模型但不懂业务；
- 咨询顾问交付报告，FDE 交付的是跑在生产环境里的系统。

一个被反复引用的数据是 MIT NANDA 的调查：约 95% 的企业生成式 AI 试点没有产生可衡量的业务影响。问题不在模型，在部署。

**与相邻岗位的区别**：

| 岗位 | 碰客户 | 写生产代码 | 交付物 |
|---|---|---|---|
| FDE | 是（约六成时间） | 是（约三成） | 跑在客户生产环境的系统 |
| MLE | 否 | 是 | 模型与训练管线 |
| 解决方案顾问 | 是 | 否 | 方案与报告 |
| 技术支持 | 是 | 偶有 | 问题闭环 |

剩下的时间花在「把现场经验沉淀回产品」——这是 FDE 区别于驻场外包的关键。

**能力交集**：能写生产级代码 + 能跟非技术高管讲清路线 + 现场排障不掉链子，三者缺一都会被卡住。

## 2. OPC：一人公司

一句话：创始人主导决策与创意，把市场分析、研发、内容、客服等流程交给 AI 工具集群，以单人完成商业闭环。英文 One-Person Company，也叫「超级个体」。

| 维度 | 自由职业者 | OPC |
|---|---|---|
| 卖什么 | 自己的时间 | 一套可复用的产出系统 |
| AI 的角色 | 辅助工具 | 研发部 / 市场部 / 生产车间 |
| 收入上限 | 受工时约束 | 受分发与产品约束 |
| 关键能力 | 专业交付 | 编排 |

核心转变是**把 AI 当作管理层而非任务工具**：你设计流程，AI 执行流程。

政策层面，2026 年多地已把 OPC 纳入产业规划（广东、深圳、杭州、云南、湖北、安徽等），据不完全统计已有 20 个省份发布百余项专项政策；存量上一人有限责任公司已突破 1600 万家，占企业总量约 27%。这些数字随时间变化，引用时注意口径。

**四类杠杆最高的赛道**：

| 赛道 | 做什么 | 为什么适合单人 |
|---|---|---|
| AI 工具与服务 | 轻量工具、企业自动化集成 | 你成为别人的生产工具供应商 |
| 数字内容工厂 | 短剧、图文、小游戏 | 产能不再受人力约束 |
| 垂直专业服务 | 细分行业咨询、报告、合规 | 领域知识是护城河 |
| AI 技能培训 | 教别人成为超级个体 | 需求随生态增长 |

**三条底线**：不要过度堆工具（找到持续痛点才是目的）；财务必须隔离（账户混用会丧失有限责任保护）；先卖服务再产品化（有人付钱之前只是想法）。

## 3. Token：共同的成本项

FDE 与 OPC 最终都指向同一个成本项。Token 是模型处理文本的最小单位，也是计费单位：API 按输入输出分别计价，上下文窗口容量也用它衡量。中文大致可按 1 字 ≈ 0.6～1 个 token 粗估，实际以分词器为准。

对这个群体，Token 直接等于边际成本，它决定三件事：

- 一个 loop 每天自动跑一次是否划算；
- 该不该把高频、原子化的判断交给便宜的小模型或决策模型，把规划留给昂贵的大模型；
- 该选订阅制还是按量付费。

注意别混淆两个「Token Plan」：套餐名说的是订阅产品，而这里是计量单位，同一个词两个层面。

## 4. 回到自己的位置

| 你现在的位置 | 建议从哪看起 |
|---|---|
| 想进 AI 落地岗 | FDE 一节 → 补 CLI 与 IDE 工具链 |
| 想用 AI 做自己的产品 | OPC 一节 → VibeCoding 范式 → Coding Plan 成本 |
| 在企业内推动 AI 落地 | 端到端实战 → 回到能力拆解 |
| 只想提升日常效率 | Claw 产品 → 办公向工具分支 |

## 5. 数据可信度提醒

这一篇讲「人和钱」，两类事实变化都快，引用时注意口径：

- 岗位数来自招聘平台统计，衡量的是招聘帖数量而非在岗人数；
- 薪资数据 base 与总包混用，头部与中小公司差异极大；
- 公司存量是快照，会随时间增长；
- 政策数量为不完全统计，地方文件更新频繁；
- FDE 是岗位概念而非职称，不同公司的 title 可能不同。

建议每季度复核一次薪资与政策数据。

## 写在最后

十六篇走完，这套全景从模型与数据层一路讲到人与商业。真正决定差距的，往往不是记住了多少个工具名，而是两件事：**能不能判断某个工具解决的是哪一层问题**，以及**能不能在真实约束下做出取舍**。工具会持续换代，这两件事不会。
