## 2. 评测与榜单

| 站点 | 价值 | 使用建议 |
|---|---|---|
| Artificial Analysis | 模型价格 / 性能 / 延迟对比 | 重点看 Quality vs Price 象限，找性价比最优 |
| OpenRouter Rankings | 模型热度与调用占比 | 排名反映真实使用量，比宣传可靠 |
| LMArena | 对话能力对战榜 | 偏人类偏好，适合选对话体验，不适合选推理 |
| MTEB Leaderboard | Embedding 模型排名 | 筛中文任务，关注 Retrieval 子榜 |

榜单的使用逻辑要分清：

- 选推理模型：Artificial Analysis（客观基准）+ OpenRouter（使用量）；
- 选对话模型：LMArena（人类偏好）+ Artificial Analysis（基准）；
- 选 Embedding：MTEB（中文 Retrieval 子榜）；
- 发现新模型：OpenRouter Rankings + Product Hunt。

**单一榜单不能做决策**。榜单衡量的是平均表现，你的业务只关心特定分布；把榜单当粗筛，用真实样本做终选。

## 6. 值得持续关注的方向

- **Claw 生态**：国内产品密集，安全机制与 Skills 市场是重点；
- **Coding Plan 竞争**：定价与模型覆盖变化极快，一季度核对一次；
- **MCP 与 Skills**：每周都有新 Server 与新技能发布；
- **Agent 框架融合**：Microsoft Agent Framework 统一了 AutoGen 与 Semantic Kernel，行业从分散走向统一；
- **GraphRAG 与 Agentic RAG**：正在成为企业知识管理的新标准。

## 7. 信息获取的一条纪律

这个领域的信息噪音远大于信号。一个可用的过滤规则是：**只看能复现的内容**——有代码、有数据、有实验条件。榜单排名、厂商宣传、趋势预测都属于「看过即可」，不必投入整理成本；真正值得记下来的，是能在自己环境里跑通的那部分。
