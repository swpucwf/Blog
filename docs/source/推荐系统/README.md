# 推荐系统

> 内容整理自开源教程 [fun-rec](https://github.com/datawhalechina/fun-rec)（《深度推荐算法实践》），作为参考笔记。

从级联架构到生成式范式的推荐算法笔记：上篇覆盖协同过滤、向量召回、双塔、序列召回、特征交叉、多目标与多场景建模、重排；下篇聚焦生成式推荐，涵盖 Tokenizer、Scaling Law、端到端建模、推理型推荐与扩散模型；最后以生产级项目串起离线与在线链路。

## 内容结构

- **上篇·级联架构**：召回 → 排序 → 重排
- **下篇·生成式范式**：生成式基础 → 规模化架构 → 端到端建模 → 推理与扩散
- **收尾**：生产级电影推荐系统
